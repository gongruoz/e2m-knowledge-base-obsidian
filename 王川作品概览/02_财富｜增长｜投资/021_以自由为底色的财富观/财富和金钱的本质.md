# 财富和金钱的本质

摘要: 所有的东西最终都是[[复利]]的积累。金钱的复利只是行动和思考的复利的积累的滞后的体现。不要只关注金钱的复利而不关注更本质的行动和思考。

# 财富的本质

财富的本质是能量和信息的效率。只要别人的能量和信息技术的效率超过你，你的东西很快就一钱不值。

财富的积累，不在于你局部的事情做得有多好，而在于：你做的东西是不是世界上最好的?

如果（大概率）不是，那么世界上最好的系统上的资产，你是否有参与进去，让自己也分一杯羹?

财富的迁移往往是看不见的，突然的跃迁。随时准备抛弃过去，跃迁到能量和信息效率更高的系统上。

# 金钱的本质

金钱的本质，是对稀缺的资源，尤其是大众都想获得的稀缺的资源的控制力。AI 将不断重新定义稀缺资源，所以不要光盯着传统意义上的金钱的定义，要不断设身处地地体验和想象 AI 创造的新的场景，在这些场景下什么是「长期的强稀缺的资源」，这样可以提前从容布局，有更多时间睡觉休息。这个问题会有应当不只一个答案。应当还会浮现出一两个新的古怪的东西，不在传统的思维模型之内。

# 财富增加来源于可组合性的增加

财富的增加，本质来自于增加自己和外部的可组合性。

这种可组合性本质来自于开放的，难以被外力破坏的自由连接。任何为了短期利益而减少自身可组合性的行为，最终必被反噬而得不偿失。

# 赚钱是为了让自己增加选择权

赚钱的本质是为了让自己增加[[可选择性|选择权]]；但让自己增加选择权的事情不一定都赚钱，甚至需要一定的投入。如果增加选择权和赚钱，两件事发生冲突，选择权永远优于赚钱。但有的时候人们常常被赚钱的幻觉所诱惑，悄悄地不断放弃自己的选择权，到最后又亏了钱，又丧失了选择权。

警惕那些以各种利益的诱惑，悄悄剥夺你的选择权的人和事。

投机时用杠杆，就是悄悄地放弃了自己的选择权。据说巴菲特曾说过，「如果你聪明，你就不需要用杠杆；如果你傻，那就更不能用杠杆了。」

# **提前布局以逸待劳**

当人们听说一个大新闻，某某人要融资或者已经融到多少多少亿元的时候，一个本能的直觉反应是：他怎么融到这么多钱，我也要去做，做得比他更好，融更多的钱！这个直觉反应可能是错的。

一个有用的观察视角是，他融到这么多钱，这些钱主要会花在哪里？然后提前布局相关的[[垄断，稀缺和财富的关系|垄断]]性资产，就在那里以逸待劳的等他。

让机会自动主动的落入你的怀抱，比盲目追逐一个（有很多其他竞争者存在的）动态目标，可能容易和轻松很多。

# 资产升值来自持续增长的真实需求

让资产长期升值的本质动力之一是资产背后的利润增加（暂不考虑利率和其它因素）。利润本质是外界对你的产品有真实需求，愿意支付的代价超过你的维护成本。所以判断某个资产升值潜力有这么几个角度：

1. 真实需求是否持续增加，可以不断衍生出新的应用和新的需求。如果你还能洞察别人暂时看不到的潜在的真实需求，那就离发财不远了。
2. 这个真实需求很难在别的地方找到替代解决方案，因此潜在用户几乎没有砍价的能力。
3. 资产背后的应用维护成本低，甚至随着用户的增加，而单位维护成本越来越低，和潜在竞争者差距越来越大。要注意，成本是个多维度的东西，获客成本，运维客服成本，还有从用户角度感受到的，使用方便角度的隐性成本。
4. 上面三个因素不能局限于静态的观察。如果能够彼此互相推动，[[自催化，正反馈循环|自我强化]]，那比孤立的单个因素的优势要重要得多。

注意，这里没有任何现金流的讨论。现金流也是一个表象，是真实需求溢出，而体现于外表的东西。现金流也可以造假。有些拥有上面四个要素的资产，乍一看，现金流很差，甚至没有现金流这个概念，但不妨碍其真实价值仍然增长迅速。

以上四点的框架，也对个人成长建设有指导意义。

而普通人常常落入的投资陷阱是：财务数据造假；单位运营成本因为某个资源瓶颈不能因规模变大而减少，导致利润有上限；资产没有垄断性，竞争者一来价格就垮了；应用单一而无法自发[[演化]]增长，等等。
