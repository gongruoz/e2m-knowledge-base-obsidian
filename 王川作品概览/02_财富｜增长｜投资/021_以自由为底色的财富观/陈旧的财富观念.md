# 低维度的「资产」是负担

很多低维度的「资产」并不是资产，而是负担。 

⽐如美国⼤部分商业房地产，房产信托，2020年疫情来临后，价格普遍在⼀个多⽉内下跌40%以上，甚⾄有的⼀个多⽉内暴跌80%以上。

幼稚的投资者以为⾃⼰购买的是⼀个有着稳定现⾦流的东西，但是不理解其现⾦流来源的维度单⼀，外界扰动可以瞬间让现⾦流归零，但各种费⽤，税务，保险等等⼀分钱还不能少。等到出了问题后，往往已经太晚了。

# 攀⽐是封闭社会的习惯

和他⼈进⾏⾦钱，地位或者名⽓等等的直接实时的攀⽐，是封闭社会的习惯，在指数增⻓的开放世界⾥会⾮常可笑。

而且以这种直接攀⽐来指导⾃⾝策略的制订，往往⾃乱阵脚，适得其反，事倍功半。

正确的观察⻆度和衡量标准应当是这样的：

1. 你是否可以健康地⽣活更多年，因此可以接触到更多潜在的指数增⻓机会？
2. 你如何能够选择周边的环境和信息输⼊渠道，改进⾃⼰的⽇常习惯，这样可以了解
和接触到更多的潜在指数增⻓机会？
3. 根据你现在收集的所有最新信息，有没有⽐你现在做的事情，确定性更⼤潜⼒更⼤的指数增⻓机会？如果有，为什么你现在还不能切换过去？任何⽆法指数增⻓的事业，很容易成为时间和精⼒的泥潭，有机会⼀定要⽴刻逃离。对于⽢愿在回报递减的泥潭⾥折腾的⼈，不管他暂时光环多么亮丽，地位多么⾼，资源有多少，不必羡慕，也不必把他太当回事。

幸福就是全⾯的，⻓期的指数增⻓。所谓中年危机就是找不到增⻓点了，也不知道如何真正有机的增⻓，想拆东墙补西墙寻求表⾯的增⻓，反而在泥潭⾥越陷越深。可以⽤投资领域的估值思路来看待⾃⼰，而不是「当前有多少存款」这种时间切⽚指标。

「时间切⽚指标」这个词⾮常贴切，这种⼈为定义的，静态的概念，误导了多少⼈的评估和决策体系。

什么样的环境很难产⽣指数增⻓？第⼀是有资源瓶颈或者其它限制⾃由贸易的瓶颈，完全⽆法绕过去。第⼆是信息传输成本，交通运输成本⾼，而且因为各种瓶颈的因素，成本降不下来。第三是⼈口和市场缺乏增量。⻓期在这类环境⽣活，⼤脑会僵化，习惯零和博弈的哲学，完全⽆法理解「指数增⻓」的概念。

我们⼀厢情愿设想的指数增⻓⽅式，往往是「有⼼插花花不发」。而⼀旦观察到「⽆⼼插柳柳成荫」时，⼀定要虚⼼研究其底层逻辑，跃过[[阈值|临界点]]后要尊重现实，果断跟上。

幸福的源泉，来⾃果断放弃「花不发」，而在第⼀时间理解并跟上「柳成荫」。

指数增⻓的神奇，在于常会出现⼏个⽉的财富增⻓超过以前⼏⼗年全部积累的现象，而且这种现象，在新兴产业[[涌现]]时，屡次发⽣。重要的课题是理解底层机制，区分伪增⻓和真正的指数增⻓，区分有很⼤潜⼒的指数增⻓和昙花⼀现的泡沫。真正理解机制后，⼈就不急了。如果你急着要发财，实际上还是没弄懂。

# 做题家深入骨髓的攀比习惯

做题家的身体习惯，本能的把科技和经济进步当成一场每天都要去攀比分数的竞赛，这样容易把自己精神搞得很紧张，而且长期看，浪费很多资源，做了很多无用功。

某某公司今天又融资多少亿上了什么项目，这是大好事啊，未来产能过剩，价格下跌，有更多价廉物美的商品，就靠他了。为什么我要去焦虑，想着要和他去竞争呢？

某某基金经理今年回报多少倍，这也是好事啊，他富了后，可以关注一下会把钱用在哪个地方消费，然后在那里提前等他。为什么一定要模仿他的策略，和他攀比某一年的回报率呢？

他如果加杠杆，那未来爆仓的可能性比较大，砸锅卖铁甩卖优质资产的可能性也更大，也可以在这方面关注一下呀。

# 正确的攀⽐⽅法

正确的攀⽐⽅法是在经验和⽅法论上和世界上各⾏业最优秀的⼈攀⽐（学习），在最终的结果上和过去的⾃⼰攀⽐。

普通⼈的直觉是在结果上羡慕那些外表最优秀的⼈，试图和他们攀⽐，每天看到巨⼤的差距，就⽆⽐焦虑。但并没有试图去理解和学习底层真正的⽅法论，所以这种焦虑变成⼀种空中楼阁式的驱动⼒，好⽐汽⻋设在空档上还不断踩油⻔，费了很⼤劲仍然没有进步，甚⾄最终损耗更多。

⼀旦进⾏错误的攀⽐，就等于要强迫⾃⼰在规定时间内完成⼀个不可能的任务，就势必对⾝⼼造成严重  的，甚⾄不可逆的损害。反过来，正确的攀⽐，你很清楚⾃⼰在不断进步，过了某个⽆法事前预测的节点后产⽣⾮线性突变，得到了丰硕的成果，然后会发现那些以前你曾经羡慕的别⼈的成就，已经让你⽆感了。

# 所谓「搞钱」

中⽂社区有个常⻅的词叫「搞钱」，窃以为这种思维存在框架性的错误。如果你做事的效率和别⼈差不了太多，再怎么搞也搞不了多少钱。但如果你可以把你做的事在各个层⾯规模化扩展化，能不断重复引⽤，在更⼤规模的用户或读者群上分摊成本，⽇积⽉累，那么你的效率⾃然越来越⾼，钱就⾃然来了。

# 陈旧的资本概念

如果资本效率提⾼⼀千倍，资本家就没那么重要了。未来属于智本家。
