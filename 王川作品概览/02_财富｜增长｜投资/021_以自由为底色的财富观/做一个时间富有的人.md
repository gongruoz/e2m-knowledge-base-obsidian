# 做一个时间富有的人

摘要: 要达到富有，先要有正确的对于富有的观念和目标。理想的富有状态应该是一种时间的冗余。
章节: 自由价更高｜自由与稳定不可兼得｜最大的财富是闲暇时间｜更多的金钱不是最终的目的｜最重要的荣誉是时间冗余｜给自己太多时间压力，就是减少自己的选择权｜赚时间，而不是赚钱

# 自由价更高

身体（健康）自由 >> 时间自由 >> 财务自由。 实际上对有心人而言，五年的财务自由（就是有可以支付五年以上生活费用的储备）就差不多够了，此后应当严格保持「身体自由和时间自由」绝对优先，在此基础上做一些自己真正有兴趣钻研的事情。 不要被其他人构建的庸俗的「财务自由」概念所混淆视听，而放弃了真正重要的自由。

# 自由与稳定不可兼得

「稳定现金流」这个人造包装的概念，只有在中央银行这个人造机构存在的时候才看上去有意义。真正追求自由者，应当拥抱和欢呼「不稳定的财富流」，这才是世界运作的真相。

「中央银行」这个东西的[[涌现]]，本质是因为很多人无法承受不可预测的，但迟早会出现的信贷萎缩的冲击，尤其是信贷萎缩到极点，经济极度萧条时，呼吁中央银行出手，人为操控信贷扩张的群体政治压力非常大，变得不可阻挡。这也给靠近中央银行的一大群权力寻租的人们以可乘之机，以极低的代价来攫取和稀释那些真正辛辛苦苦靠劳动创造价值的人的财富。

新技术，给人们更多的选择。让喜欢中心化的人继续中心化，不喜欢中心化的人去中心化吧。

# 最⼤的财富是闲暇时间

最⼤的财富是闲暇时间，对闲暇时间的最⼤杀⼿是⼀对⼀的交流，给⼀个⽼板打⼯，或者做⼀次只能卖给⼀个客⼾的定制服务。

有更多的闲暇时间，才能深⼊思考更多前瞻性的问题，才能避免重⼤战略性的浪费和失误，从而有更多闲暇时间，形成良性循环。警惕任何可能打断这种循环的⾏为误区。

⼈对⾦钱的需求是有限的。但做⼀个时间富有的⼈，到后⾯越来越重要。

⽐尔盖茨⽐我⼤将近⼆⼗岁，但我的时间富有程度可能要⽐他多远不⽌⼆⼗年，因为未来⼏⼗年内⽣物医学科技的发展进步，可能导致⼈类寿命⻓度的上限，出现较⼤幅度的跃迁，这是多少钱也换不来的。

现在可以做的：间歇性断⻝拉⻓到⼀天⼆⼗小时，偶尔可到三⼗六小时达到细胞⾃噬，经常⼾外爬⼭，晒⼀点太阳但⼜要注意不要过头，适度运动但⼜不要太激烈。少吃⾁，少喝酒。多研究测试，适度打破常规的禁忌。

如果你专注于延⻓寿命，那么总能赶上下⼀场游戏和[[范式转移]]，没必要 FOMO (唯恐错过)。

# 更多的⾦钱不是最终的⽬的

巴西企业家 Ricardo Semler 说，当利润超过⼀个基本最低值后， 更多的利润并不是保证企业⽣存所必须的。不惜代价而单纯追求更多利润，好⽐发现监狱⾥有空的牢房，然后认为没有抓⾜够多的犯⼈⼀样。对于管理监狱的政府而⾔，⽬的不在于抓更多犯⼈来降低牢房的空置率，而是努⼒降低犯罪率，减少犯罪对于社会造成的损失。

同理，当收⼊超过⼀个基本值满⾜基本⽣活需要以后，更多的⾦钱不是最终的⽬的，而是提⾼赚钱的效率，不断增加私⼈⾃由⽀配/做⾃⼰想做的事的时间。这个概念可以叫做 minimum viable profit (最小可得利润)。但是如果盲⽬以扩张为⽬的， 那么可能不再 viable (可得)，或者不再 profitable (划算)。反之，保持⾃⾝的效率和灵活性， 更多的利润迟早会⾃然涌现。

# 最重要的冗余是时间冗余

最重要的⼀个冗余是时间冗余，有⼤把的闲暇时间去做⾃⼰愿意做的事情，而把在不愿意做的事情上耗费的时间尽量压缩到接近于零。

时间冗余的第⼀个杀⼿是：浪费时间去辩论，或试图说服认知不同的⼈接受⾃⼰的观点。

时间冗余的第⼆个杀⼿，是没有把⾃⼰经常要做的⼀些事情⾃动化，然后发现⾃⼰忘了，⼜要耗费时间精⼒再⼈⼯⼲预。

时间冗余的第三个杀⼿，是没有注重于可以不断多次重复使⽤，积累的⾏为；而耗费⼤量精⼒在低价值，⽆法重复利⽤的⾏动上。

时间冗余的第四个杀⼿，是没有勇⽓和意愿隔断各种低效甚⾄有伤害性的社交应酬，让⼀些蠢⼈随便地接近你的空间，或者允许⼀些群体的错误⻛⽓潜移默化地⼲扰你的独⽴思考。

时间冗余的第五个杀⼿，是没有注意「节制饮⻝ - 适度运动 - 充⾜睡眠」。随着年龄增⻓，各种肩酸背痛，视⼒下降，神经衰弱，⾼⾎糖⾎脂，⼼⾎管等毛病不断加剧，恶性循环，脾⽓也越发暴戾，迅速滑向⽼年痴呆，成了⼀个事实上的废⼈。

时间冗余的第六个杀⼿，是本来可以花 N 个小时把⼀个事情做得差不多⾜够好就收⼿了，硬是要花 3N，4N 甚⾄更多倍的时间，仅仅把效益再提⾼百分之⼏而已，甚⾄画蛇添⾜，多余的努⼒反而把事情搞砸了。 美国95%的共同基⾦⼗年的⻓期回报⽆法跑赢标普500指数，剩下5%的基⾦的平均年化收益⼀般也就⽐指数多不到1%而已。

判断⾃⼰「时间冗余」的⽔平的⼀个⻆度是，你如果什么都不做，⼀个⽉，三个⽉，甚⾄沉睡多年再醒来，你的状况（财务或者别的⽅⾯）是不是可以维持现状，甚⾄会变得⽐现在更好? 如果有哪些地⽅需要⼈⼯⼲预，是否可以现在就未⾬绸缪，把它预先⾃动设置好？

「时间冗余」并不完全等同于「⾼效率」，另⼀个⻆度是当意识到⾃⼰的⽅向是错误的时候，可以迅速调整[[试错与纠错|纠错]]的能⼒。如果⽅向错误，意识到错误后因为各种限制而⽆法迅速抽⾝离开，那么不管效率多⾼，也是枉然。

任何事情，如果不能随时抽⾝离去，而要时常事必躬亲，是⼀个潜在的时间上的负资产，是对时间冗余的巨⼤损害。往往⼀开始没有在意，出了问题后才意识到代价巨⼤。还有⼀点，千万不能随意接受任何⼈给你设定的某个截⽌⽇期，这样⼈为摧毁⾃⼰的时间冗余，可能酿成⼤祸。多年前我有⼀位⻓辈，被⼈催着要去参⻅⼀个会议，天⽓不好还要着急赶路，遇上⻋祸，不幸去世。

# 给⾃⼰太多时间压⼒，就是减少⾃⼰的选择权

给⾃⼰太多时间压⼒，就是减少⾃⼰的[[可选择性|选择权]]。这种坏习惯积累久了，会有⼀天把⾃⼰置于没有任何选择的地步，从而造成⽆法挽回的重⼤损失。

同样⼀件事情，如果有时间压⼒，就会⾮常痛苦烦躁; 如果没有任何时间压⼒，洗碗，叠⾐服等等家务，也可以感觉和冥想没有太⼤差别，还可以顺便把事⼲了。同样是运动，⽐如游泳，如果⽼惦记着要计时，就会觉得不爽，变成了⼀个任务。如果随意⼀些，没有时间压⼒，就可以玩很久而不觉得枯燥。

类似的还有旅游，如果跟着导游每天赶路，算时间，填鸭式的旅游，总是感觉哪⾥不太对，⼼情没有那么舒畅。但如果更随意⼀些，则会回味⽆穷，乐此不彼。

提⾼⽣活质量的⼀个⻆度，是把有时间压⼒的活动，尽量压缩到⽇常的10%以下。这样可以保持⽐较⻓久的内在动⼒。

意识到过去⼏年⾃⼰在不同领域的⼀些意想不到的进步，本质都是因为有闲暇时间，所以就可以东摸摸，西碰碰，摸索出来⼀些新的发现，有效提⾼⾃⼰的能⼒，改善⾃⼰的学习或⽣活环境。

让⾃⼰有很多闲暇时间，本质等于给⾃⼰去杠杆。整天忙得昏天⿊地，本质等于满仓投机，这样就没有任何冗余，来应付未来注定要发⽣的各种意外事件。

世界是个巨⼤的 fitness landscape (适应度地形)，我们本质都是在上⾯做各种 stochastic gradient descent (随机梯度下降) 计算的小爬⾍而已。区别在于，有的爬⾍接触数据多，维度⾼，计算效率⾼，因此⻓期的实质性进步更快。有的热锅上的爬⾍，看上去很忙，爬得很快，但只是在团团转，做⽆⽤功而已。

# 赚时间，而不是赚钱

满足温饱之后，人应当以「赚时间」而不是「赚钱」为目的。

这个赚时间有两个维度，一个是投资身体健康，争取健康的活到一百多岁。

另一个维度就是不断审视日常做的事，看看是否有办法减少在它上面消耗的时间。要以豌豆公主隔了二十层棉被还能感知到那颗豌豆的极端敏感度，审视日常的活动，凡是那些让你感到有一丁点时间压力，不能慢悠悠闲庭信步的按照自己节奏来做的事情，要么出钱外包，要么考虑放弃。

线上可以搞定的，就不要线下跑老远，专门浪费时间去扯淡。能够做一次视频或者写一篇文章把问题讲清楚的，就不要巡回和多个主持人宣讲内容雷同的 podcast 。能够一次把外包流程做好，交给别人办理的，就不要每次都亲力亲为。

长期看，如果时间赚到后，实际上钱就更容易赚。比如很多好的投资机会，它的降临事前无法预测。真正机会来的时候，很多人一是没有弹药，二是忙于日常的各种琐事，平时根本就没有时间关注，更谈不上在关键时刻有精力出手了。

以赚钱为导向的人，势必把自己的时间冗余压榨到极致，不仅危害健康，而且常常处于一种心急火燎的精神状态，日常体验并不开心，会影响体内激素平衡，睡眠不好，心血管疾病风险也更大。

以赚时间为导向，因为日常的注意力是处于一种极为富余的状态，每天心情相对愉快放松。虽然为省时间要支付一些代价，但因此在健康上获得的回报和富余时间带来的更大接触面的潜在利益，可以高出好几个数量级。

所以要慢慢养成一个习惯，每天不是看又赚了多少钱，而是先自省，「有哪些地方又做了改进，赚了更多时间」？

实际上有大把时间，钻研自己有兴趣的课题（不一定是直接赚钱），可以让人极为愉快，而且不妨碍长期赚大钱。因为如果你足够知识诚实，你感兴趣的课题一定会很有价值，你迟早有办法轻松的把它换成钱。
