# 指数增长的特点

[[指数增长，S 曲线|指数增长]]的特点是，一旦走上指数发展的正道，最后一年发展的增量会超过之前几十年积累的总和。这个曲线的陡峭程度远超人的直觉所可以理解。

智人存在 20 万年，但文字的[[涌现]]也就大约五千多年的历史（位于现在伊拉克的古代苏美尔人），这是 40 : 1 的比例。

而这五千年来真正科技突飞猛进，1840 年大概是个分水岭，火车、电报、照相这些技术的商业化都是在 1840 年前后开始，也就是不到 200 年。这是大概 25 : 1 的比例。

而这过去两个世纪里，全球化的迅猛发展的一个转折点是 1993 年 world wide web 的涌现，也就是三十年的历史。

转折点之后的人，看转折点之前的人的生活工作状态之落后，会有一种极为惨不忍睹的感觉。

转折点之前的人们，按照自己的认知和习惯去计划未来，如果没有考虑到高科技的指数发展，最终都会被证明是荒谬的、无效的、驴唇不对马嘴的、可悲的。

如果说有什么教训可以吸取，那就是：

1. 高科技发展会导致未来很多事物在一年的时间的增量，超过之前的几十年、几百年、几千年的积累。
2. 这个现象会在很多不同领域持续、重复发生。
3. 这意味着多活几年的价值在未来可能会有决定性的意义，因为那几年在某些技术领域涌现的增量，决定你是否能够跃迁到一个现在无法想象的新世界，在新的技术条件下把自我意识以一种现在无法理解的方式保存 / 复制 / 传播 / 组合，等等。

传说中的龟兔赛跑，兔子输了的原因是它在睡觉，然后乌龟慢慢超过了它。

真实世界中的龟兔赛跑的结局：兔子最终输了，恰恰是因为它用力过猛而睡觉睡得太少。兔子开始屡屡得手，遥遥领先，结果有一次因为 fomo 而买在高点，遭遇了 margin call，被迫割肉在低点。兔子每天忙忙碌碌，心急火燎，伤害了健康。乌龟虽然比较慢，每天大部分时间在睡觉和锻炼身体，起初落后兔子一大截。但兔子被强行平仓之后，就突然悄悄消失在乌龟的视野中。某一天乌龟想起当年见过的兔子好久没消息了，查了一下才发现他早已英年早逝。

# 10x 比 2x 更容易

《10x 比 2x 更容易》，好书。强迫你改变现有的线性思维框架，有张有弛地为未来的指数增长机会全面准备。

有必要把这本书的核心精神总结一下：

1. 很多人因为一种不假思索的本能，以为财富的增长就是对现在做的事情上加倍努力，这是 2x（两倍数）的思维。
2. 10x（十倍数）的增长，长期看，实际上比两倍更容易。因为，你一旦以 10x 的视野来要求自己，就会主动强迫自己过滤、放弃、拒绝掉各种长期增长潜力有限的机会（甚至是骗局），你会让自己高度聚焦，只做哪种有潜力让自己十倍增长的事情。这个过滤方式，对人也适用。
3. 因为你拒绝了很多低价值机会，反而时间更多了。更多的时间让你可以聚焦深入的研究，提高自己在底层用第一性原理识别和捕捉高价值机会的能力。
4. 因为你在架构设计上就强迫自己不断积累各种新的微小的优势，迟早会有一天你会获得突破，实现 10x 的梦想。
5. 回到第一步，重新审视自己的日常工作学习，再重新过滤放弃旧的低价值习惯，开始下一个 10x 的篇章。

科幻小说家 Frank Herbert 有名言：「追求自由，你就会成为欲望的奴隶；追求自律，你就会找到真正的解放。」对低价值事物的严格筛选过滤上的自制，正是获得高价值成长的解放之路。

我的理解：因为自律，所以很多地方可以挖掘出更多的潜能，在螺旋式上升的过程中可以做越来越多的事情，从而获得真正的解放。此后再回顾最初你本能追求的自由，自然会觉得不屑。

这个十倍数的实操，简单，但并不容易。需要对自己狠一些，切断一些低价值的关系和行为，和不断拖你后腿的牵挂/妄念。你每天必须要有一段时间和自己的潜意识作对，要能坚持，不进则退。就好比如果你不注意每天称体重，就容易不节制饮食而变得肥胖一样。当然最后收获的好处，意味着所有之前的自律，都是值得的。

# 通过创作和迭代的方式实现复合增长

⼀份领薪⽔的⼯作，基本不能让⼈实现复合增⻓：因为在这类岗位上，基本上你就是个螺丝钉，会被要求完成指定的任务，基本上没有⾃由探索和发挥创意的空间，即使⾃⼰想做这类探索，也很难会⽴刻得到⽼板的⽀持和⿎励。

这也造成另外⼀个问题，打⼯久了后，⼈是⽆法理解「复合增⻓」这个概念的，而更习惯于接受别⼈的指令，或者抄袭前⾯的⼈，短平快地达到某个⽬的了事。

⼀般⼼智健全的⼈，都会找到某个东西让他⾮常有兴趣废寝忘⻝去忘我探索，不管是画画，写⽂章，写代码，还是创作什么别的东西。只要这类创作探索的成本⾜够低，就可以⾃由迭代若⼲次，达到极⾼的质量，通过各种社交媒体渠道发表，最终能够找到⾼溢价的变现⽅式。

如果你每周要被迫给⼈打⼯，包括在路上的时间是 N，给⾃⼰定个计划，花四到五年时间，把 N 降到 10 以下，直到它接近于零。剩下的时间就可以⾃由探索创造了。很多伪创业是成本极⾼的盲动，只会适得其反。

⼤部分⼯薪阶层每周⼯作加上班来回的时间接近五⼗个小时。本质等价于每周要做接近五⼗个小时的奴⾪。如果把 N 压到10以下，有⾃由时间去探索创造，其它问题基本迎刃而解。为了伪创业而牺牲实质的⾃由⽀配时间，被迫做很多不喜欢的事情，变成另⼀种变相的奴⾪，也很不划算。

[[摩尔定律]]之所以可以持续复合增⻓，是因为底下存在上百个不同微创新和技术路线在彼此竞争，你看到的只是冒头的增⻓最快的那个技术路线而已。同理，个⼈的复合增⻓，也应当争取在多个不同的增速最快的⽅向/领域上同时布局，定期强⾏调整，这样不⾄于全部资源卡在某个错误路线上浪费很⻓时间。

抄袭者之所以总是⽆法赶上创新者，是因为抄袭者只能做到形似，而创新者底下有多个不同的微创新和技术路线为未来发展提供强⼤后劲，这是外⼈看不到的。

假如你为了前进⼀小步，需要有⼗个部件同时到位，但是为了达到这个状态，你可能踩过⼀百个坑，你的知识/⼯具库⾥有⼀百个备份（但质量和性能参差不⻬）的部件。当形势改变时，你有能⼒迅速微调各种参数，调⽤改进其它组件来继续[[演化|进化]]⽣存。但抄袭者完全没有这种应变能⼒，突变时容易突然死亡。抄袭者只会沾沾⾃喜⾃⼰节省了研发费⽤，占了小便宜，今朝有酒今朝醉。

当代各国的⾼等教育，没有看到谁系统性地教授「复合增⻓」这个概念。⼤多都是照本宣科，死记硬背，培养的⼤多是⼀个模⼦的⼯业化快餐式的⼈才。浪费了多少⼈的⻘春，罪过罪过！
知识和⼯具库⾥的部件多了，还有⼀个好处：你总是可以在某个⽅向做⼀些低成本的测试，得到⼀些[[自催化，正反馈循环|正反馈]]，让你进⼀步改进，也同时丰富了你的⼯具库。这样你始终乐在其中，有动⼒不断摸索。爱迪⽣在那个年代能够活到 84 岁，⼤概和他这种其乐融融的⽇常⽣活状态有关系。

# 挣⼯资的陷阱

挣⼯资的感觉，可能是个巨⼤的陷阱。

因为有意⽆意的骗⼦，常常会把有巨⼤⻛险的东西，包装成⼀个⻛险低，收益稳定，像⼯资⼀样定期发放的东西。

因为只有这样包装，多数⼈才好理解和接受。否则卖不出去。
很多⼈为包装/看上去稳定的东西，可能突然⼀夜之间就没了。也有极少数看上去极不稳定，波动极⼤的东西，可以让你短时间内获得⼏⼗年稳定挣⼯资也得不到的收益。世界本来就是不稳定/波动极⼤的，想过舒服⽇⼦而接受了别⼈包装后的童话，就必须承受童话破灭后的苦果。

这个事情是⽆法改变的。⼤部分⼈，注定会选择表⾯稳定而⻛险被掩盖的路径。⻛险爆发后这批⼈很多会被灭掉，系统进⼊⼀个新的稳态，然后新的⼀批⼈⼜会选择新的表⾯稳定而⻛险被掩盖的路径。

利息⾼的，⼀般都是劣币。良币的价值增⻓是内在的，不需要靠借贷来获得收益。如果有⼈在⽆抵押的情况下给某个良币许诺⾼利息，⼀般最终结局是赖账违约。在劣币的环境下呆久了，会对收利息的思维模型过于偏执，而⽆法适应良币的思维模型。

# 个⼈复合增⻓的障碍

如果说复合增⻓是世界第⼋⼤奇迹的话，对于个⼈而⾔，复合增⻓的障碍第⼀是上杠杆投机被强平，⼀夜回到解放前；第⼆是卡在某⼀个没有增⻓前途的⽅向⾥，拒绝改变发展⽅向，⻓期低⽔平的重复。

对于国家而⾔，第⼀是因为战争而毁灭财富（外敌⼊侵，或是可汗死了后权⼒⽆法顺利交接，⼏个继承⼈⼤打出⼿，每隔⼗⼏年这样折腾⼀次）， 第⼆是经济模式单⼀，没有技术升级。

很多时候⼈们喜欢把别⼈的成功归咎于⼀个单⼀的原因。但真实原因往往就是⻓期的，⽆间断的复合增⻓。归于单⼀的原因，是因为⾃⼰想要偷懒找捷径迅速达到别⼈成功的位置。但即使表⾯看上去做到了，别⼈可以继续⾃发地复合式的增⻓。而模仿者没有基础，很难继续跟随。

⽆论是个⼈，公司，国家，业务模式都不能太单⼀。否则单⼀业务遇到挫折或暂时的增⻓瓶颈时，⾃⾝现⾦流为负，会引发连锁的负⾯崩溃效应，苏联在1986年油价⼤跌后的表现就是⼀例。

但⼀般⼈性都是：单⼀业务⾼歌猛进时，根本不屑于培育和发展其它业务，等到后⾯再想抱佛脚时，肯定来不及了。

复合增⻓的⼀个⽭盾特点是：如果⽅向和⽬标太明确，过了市场饱和点之后会发现很多⾏为全是⽆效或极低效的，⽩⽩消耗能量，即使⾃⼰主观上很努⼒；但如果坚持在最开放的搜索空间⻓期摸索，短期看似⽆所事事，没有进步，⻓期总是会在意想不到的地⽅找到指数增⻓的突破口。这也是为什么回撤 (drawdown) 和夏普⽐率 (sharp ratio) 这些概念，对于⼀个⻓期主义者而⾔，本质都是狗屁, 会有反效果。

复合增⻓包括⾦钱的增⻓，知识和思维模型的增⻓，信息输⼊和输出渠道的增⻓，等等。在此基础上，还是活得⻓最重要。因为和今⽇的新商业范式相⽐，你如果回顾⼗年前很看重的东西，会发现⼤多不屑⼀顾。所以有理由相信，⼗年⼆⼗年之后，新的商业和技术架构涌现，让你会对2021年这些东西也不屑⼀顾。习惯了云计算的⼈，对于以前企业要雇⼀⼤堆 IBM 或惠普的顾问做项⽬，肯定觉得不可思议和不屑⼀顾。

真正的效率提⾼，意味着不断重复利⽤过去的成果去构建更复杂的产品，或者把同样的成果和产品变着花样推⼴到更⼤的市场上去；如果被迫东⼀榔头西⼀棒⼦地搞各种杂事，或者要去做各种定制性的服务，那么⼀个⼈很难系统性提⾼⾃⼰的效率，缺乏实质性竞争优势，⽆法有效复合增⻓。

关于重复使⽤: ⽹⻜ (Netflix) 2013年做原创电影时，很多⼈⽆法理解，因为耗费巨⼤。但原创电影可以⽇后⽆数⼈反复观看，分摊到若⼲年的时间，和（2013年的）四千四百万订⼾上，这个投资就没那么昂贵。到了2021年，全球订⼾超过两亿，⽉费从2013年的⼋美元涨到现在的15美元，就会发现，原来的投资⾮常划算。

⼈为什么会卡在⼀个没有增⻓前途的⽅向⾥? 很⼤原因是缺乏对外⾃由连接和⾃由贸易的基础设施。贸易机会来⾃彼此⽣产效率的差异。你有些事情效率⽐小明⾼，把你的货物或服务卖给小明，就可以提⾼⼤家的共同效率，反之亦然。海量的⾃由连接，和⾃由贸易的环境，就会让复合增⻓⾃然涌现。

英国之所以⼗九世纪成为世界霸主，很⼤程度上是因为1688年光荣⾰命解决了权⼒交接的问题。而且对外扩张中，能赚钱就打，不能赚就收⼿。很少深⼊殖⺠地内部⼲脏活，主要集中资源控制港口和交通要道来收税。这样迭代两百多年⾃然出奇迹。这种模式最终因为市场的饱和，和德国⼈的挑战而终结。
简单模仿看得⻅的成功者的道路，前途是有限的。⼀般前⾯的开拓者如果把坑占了，你要跟着过去，他吃⾁，你最多只能喝点汤。所以⼀定要摸索属于⾃⼰的独特的路线。

有机的复合增⻓过程中，当事者会有⼀种「节节贯穿」的舒适感，可以感受到能调动的资源和对外输出的能量和效率在不断层层迭代的持续增⻓。而坑蒙拐骗/贪多求快/⾃欺欺⼈的增⻓，总会感觉到哪个地⽅有瓶颈，稍不慎就会鸡⻜蛋打；或者⽼是要重复做⼀些事务性的⼯作，效率和以前⽐没有任何提⾼。

# 识别可以长期复合增长的资产
