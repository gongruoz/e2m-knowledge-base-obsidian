# 可复合增长的慢慢积累

慢慢积累的人很难暴富，因此在积累早期，一般很难进入媒体报道的视野。而一百个激进的赌徒中，总是会有一小撮暴富，只不过今天暴富的这一小撮，明天可能悄悄破产。而明天暴富的一小撮，又和今天的是完全不同的一群人。

但媒体会把注意力持续放在不同时期[[涌现]]出来的赌徒上面，给不经世事的观察者一个错误的印象：以为这些冒头的赌徒占据的是一个高大上的生态位。于是，他们真诚地去模仿这些赌徒的策略，但实践中往往是每次看上去很热闹、很接近成功，然后又频频碰壁，被打回原形。

---

复利不是说喊个口号「我要复利！」它就来了。

复利的第一个关键，是永远不把自己置于毁灭性风险之下。

第二个关键，是尽量把自己置于一个潜在回报远远大于潜在风险的定位上。

但很多人在凭直觉决策时，心理上往往基于某个自我欺骗的叙事，锚定于潜在回报 R，而完全不考虑背后的风险。这样实际操作时，R 成了封顶的上限，而下限往往是彻底亏完。所以，每次觉得自己会有复利，但总是定期把之前 N 年的积累突然全部亏光。

---

可复合增长的慢慢积累，更大的神秘之处，不在于它最终导致巨大的数字，而在于它在最初很长一段时间内不会导致巨大的数字。

# 通识⾃我教育不是⽩积累的

意识到以前读书和⼯作时，最不爽的感觉是：

因为在陌⽣体系内打基础的初期，是⼀个极为吃⼒和⻅效慢的过程，因此和其它智⼒平庸，但是已经在现有体系内有相当积累的⼈相⽐，会有很⻓⼀段时间感觉像个狼狈的傻⼦。这也是为什么很多⼈情愿在夕阳产业苟延残喘也不愿直⾯现实的⼀个原因。

而且在别⼈已经开拓的体系内追赶补课，没有⾃发兴趣驱动的强⼤动⼒很不爽，⻝物链顶端的位置早已被他⼈占据，即使花很多时间也很难获得超值的回报。

最终要获得突破，⼀定要建⽴属于⾃⼰的独特的体系。在⼀个多维度的信息世界，只要涉猎⾜够⼴（宽度），下⾜够多的功夫（深度），积累⼀定时间后，⼀定能够以你⾃⼰独特的⽅式，实现突破。

这种做法有两个好处，第⼀，⾃⼰探索的过程中，以兴趣为导向，始终会有强⼤的内在动⼒。第二，因为是多维度的探索，因此⾃由度和灵活度极⼤，调整能⼒极强，可以有多种组合灵活跨界，不会陷⼊某个狭窄体系⽇后被技术淘汰而⼜要完全从零开始的窘境。

涉猎领域越⼴泛，到后⾯还有个神奇的效果，就是越来越容易触类旁通，把不同领域的知识连接融合起来，发现新机会，产⽣边际收益递增的指数增⻓的效果。这才意识到前⾯各种通识的⾃我教育，不是⽩学的。但要把⾃⼰的认知解释给没有基础的⼈，难！甚⾄⼀些稍微反直觉的概念会被不懂的⼈轻浮地嘲笑。

# 积累出奇迹

很多事情就是靠积累。积累出奇迹。

可以积累迭代的东西包括：

属于⾃⼰的产品，品牌，⾃⼰的团队或客户或⼈脉⽹络，⾃⼰的财富（房产、股票等等），⾏业的经验，任何⼀个维度积累到⾜够深度，想不富都很难。

最忌讳的的是中断积累，⽐如卖了经济增⻓中⼼地区的房⼦，跑去缺乏⼈口增⻓的地⽅换成便宜的⼤房⼦，⼗年后发现财富和经济核⼼区域的⼈就拉下⼀⼤截了。

咨询业是很难积累的，很多时候你只是帮⽼板积攒 billable hour 的⼀个 warm body，到处跑来跑去，⾮常⾟苦。客户资源根本和你没有半毛钱关系。所以你会看到很多刚毕业的学⽣到⼀些咨询公司⼲了⼏年就跑了。

积累的早期看上去会⽐较窘迫，⾃⼰的信⼼也会不⾜。这时候会有贩卖⼼灵鸡汤者教你如何表演得更优雅。但表演往往对于你的积累产⽣负⾯效果，让你忽略问题本质，而不断浪费资源在没有回报的表演上，时间⼀⻓，岁⽉就蹉跎了。

换个⻆度看，⼼灵鸡汤贩卖者是⾮常可恶的，因为他们客观上忽悠⼈们相信了他们的表演艺术，去不断耗费资源追求虚假的⽬标，等意识到这种路径的错误，已经⼗⼏⼆⼗年浪费掉了。

# 积累在微观的体现上有多种形式

积累在微观的体现上有多种形式：

⽐如有的⾏业，刚起步时，寻找客户的时间和成本特别⾼，很多⼈熬不过去，最后就退出了。有的⼈坚持下来，而别的竞争者在⾏业周期的不同阶段因为各种原因死掉，最后客户⾃然都流到⾃⼰这边来，越来越多，口碑越来越好，而且客户互相介绍，这样单位获客的成本越来越低，单位时间的利润越来越⾼，⾃然就富了。

还有的⾏业，[[可扩展性]]极强，边际成本⼏乎为零，在积累过程中，随着客户群的不断增⼤，可以把销售价格持续降低而丝毫不影响利润，而竞争者的客户太少，⽆法⾯对这种价格竞争，就只好退出。如果能在⾃⼰的核⼼产品上不断迭代推出更复杂的新的产品，更加深度地绑定更多客户，这种积累优势就会导致利润指数增⻓，而且竞争者根本不可能超越。

积累的质量也要看市场本⾝的增速。在萎缩的市场，再怎么积累也没⽤。在⾼速增⻓的市场，即使很粗犷地积累，效果也惊⼈。

⼀些公司⽆法做到真正有机地积累，会采⽤借债加杠杆来扩张，来营造积累的假象。但如果仔细看他的利润率的变化和负债率的变化，就很容易分辨出「优质积累」和「虚假积累」。虚假积累害处极⼤，⼀旦经济形势逆转，会把⾃⼰真⾦⽩银的积累全部消耗光，倒退很多年。

真正⻅识过体验过⾼质量的积累，对于「低质量积累」或者「虚假积累」就有较强的识别能⼒，也就没有太⼤兴趣了。

短线股票交易是很难真正积累财富的，最多只是因为[[幸存者偏差]]产⽣的个例，给很多想不劳而获的赌徒制造⼀种积累的幻觉。

挖空⼼思去研究，捡区块链上的空投（airdrop）基本上属于回报递减，⽆法积累的⾏为。而且可能遇上恶意的攻击，错误授权，把⾃⼰的私钥（token）都弄丢了。

语⾔，⽂字，印刷术，计算机，互联⽹，区块链，等等，都可以看成⼀种⼈类⽂明不断进阶的「积累的」技术。积累⽔平越⾼的组织，最终不可避免地要淘汰积累⽔平低的组织。

积累出奇迹的过程中，你会⾮常精确地知道⾃⼰微观的优势具体在哪个点上，因此⾃信会不断加强。依靠⼼灵鸡汤出奇迹，你总是被⼀种模糊而⽆法迅速[[证伪]]的理念或希望牵着⿐⼦走，不断念叨着「⼼诚则灵」来⽀撑⾃⼰的⾏动。

军事领域有句名⾔，「业余爱好者讨论策略，专业⼈⼠讨论后勤」。商业领域可以类似地说，「业余爱好者讨论策略，专业⼈⼠讨论积累」。缺乏后勤的军事攻势⼏天内就会歇菜，缺乏积累的盲⽬创业很快就会现⾦流枯竭。

⼤量的积累最终还是需要⻓期⾃发的兴趣驱动，而不是苦⾏僧式地压榨⾃⼰。

# 积累的⼏个层次

积累分⼏个层次：

- 可积累
- 可持续积累
- 更快的持续积累
- 很难被破坏的，更快地持续积累

这⾥⾯最重要的是很难被破坏，其次是可以持续，第三才是更快。

很难被破坏，是指具有抽象上的「易守难攻」的特质，不⾄于被外⼈轻松地把你多年的积累摧毁。

「可持续积累」是指你积累的资源具有极好的扩展性，以⾄于⼏⼗年前你掌握的某种能⼒、资源等等，现在仍然可以被利⽤，产⽣效益。

「更快的积累」需要⼀种越来越⼴阔的全球化视野，看得越多越远，⾃然可做取舍，不断引⼊增速更快的业务淘汰掉增速缓慢的业务。

⼀旦引⼊「赛道」这个概念，而这个「赛道」是赢者通吃的话，就⼤概率⽆法积累，甚⾄把之前积累的资源全部赔进去。最好的赛道是只有你⼀个⼈能定义和参与的游戏。

第二点是，是如果自己的日常业务感觉就像个有趣的电子游戏，非常沉迷，那么自然有动力做的比别人好，也更不容易出局。

# 对正确的信号敏感

有过经验的人，才知道对什么信号和线索敏感。 另外一个角度看，如果观察到某个人对于某类事情的一些基本的信号都很迟钝无反应，就可以断定他在这类事情上毫无经验，就可以迅速过滤掉了。 而且有过多次「从没经验到有经验」的经历后，对于朝什么方向摸索可能找到有价值的信号，也会更敏感更有经验，进步也会更快一些。

建立有效经验的一个要素是时间的积累。比如说你在 t = 0 的时候观察到某个现象，当时没有能力判断这个事情以后是否会成功，失败，或者完全就是一个赤裸裸的骗局。但是到 t = N 年 （ N 可能大于 10 ) 的时候，事情终于尘埃落定，你在复盘的时候，就会恍然大悟意识到 N 年前的你观察到的某一两个关键线索有强大的预测力，其它当时很热闹的发声全是无关紧要的噪音。 这种案例积累多了，自然可以建立良好直觉。 很多人没有这种经验，本质就是缺乏时间的积累，只看到 t = 0 时候的现象，还没有看到 t = N 时候的终局，自然无法对自己的神经网络进行有效的训练.

信号和线索可以分为几类：

1. 完全无关紧要。
2. 在特定情况下有一定预测力，别的时候则没有预测力。
3. 欺骗性的，应当反向理解的信号。
4. 预测力和关联度极强的信号 （比较少见，常常被隐藏，但时间长了总会藏不住而自然流露）

# 超线性增长

@taoshenga19:

不理解超线性回报，就无法理解这个世界。超线性回报归结为两大基本原因：[[指数增长，S 曲线|指数增长]]和[[阈值]]（thresholds）。

下面是超线性回报的一般法则：

1. 寻找具有复利（或复合效应）的工作，工作可以通过两种方式产生复利：一是直接复利，在当前周期做得好，会使你在下一个周期做得更好。例如，进行基础设施假设、培养受众、发展品牌时，都是这样。二是通过在工作中学到东西获得复利，因为学习是有复利的。
2. 永远保持学习：不要过度优化你的学习，不要局限于学习那些已知有价值的东西。局限自己的学习可能会剔除潜在带来超线性回报的知识。
3. 好奇心驱动，而不要事业心驱动，放飞你的好奇心，而不是做那些人们期望你做的事。能够带来新发现的问题，往往看上去都令人费解，但是可能会带来超线性回报，比如大多数人不理解 BTC，ETH。给理解他的人带来了超线性回报。

技术的进步，以及组织重要性的下降带来了超线性回报的机会也在指数增长。一个由组织主导的世界，抑制了绩效回报的可能幅度，很多新方法来学习、赚钱、寻找同事和找到观众。

超线性回报意味着不平等。回报曲线越陡峭，结果差异就越大。寻找少数大赢家的表现远超其他所有人的领域。一种工作，如果每个人的表现都大同小异，那么它不太可能具备超线性回报。在哪些领域，少数大赢家的表现会远超其他人呢？比较明显的有这些：体育、政治、艺术、音乐、表演、导演、写作、数学、科学、创业和投资。超线性回报在一开始会很小，但回报上升得非常陡峭，付出额外的努力到达那里是值得的。
