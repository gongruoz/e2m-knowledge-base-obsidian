# ⼏个⽴竿⻅影的健康习惯

⽬前已发现的不要钱的极为有效的⽴竿⻅影的⼏个健康习惯：

1. 间歇性断⻝，减肥根本不是问题。
2. 靠墙站桩两到三分钟（⼤腿和小腿⼏乎垂直），对视⼒维护⽴竿⻅影，眼睛清亮，⾮常舒服。
3. 早晨太阳出来时到户外⼗⼏分钟，尽量让眼睛感受⽇光，对调节⽣物钟和极⼤提⾼睡眠质量极为关键。
4. 深蹲休息，可以看书看⼿机同时做任何事情。完全放松脊椎，顺便锻炼核⼼肌群，妙不可⾔。⽆需专⻔做其它康复运动，腰酸腰痛成为伪命题。

这些经验发现的越来越多，越让⼈怀疑，医学界是否存在某种刻意压制这些简单⾼效不花钱的健康信息的合谋。

还有多少其它简单有效的措施，不花钱，但⼜能极⾼提升⽣活品质，等待着⼈们去发掘？

# 结构性的不健康困境

现代人生活方式有几个结构性的原因，严重损害健康：

一是白天大部分时间在室内工作，不见日光。久坐几个小时而不动，严重缺乏锻炼和对身体肌肉的良性刺激（每天至少应当有走路 1 万步以上的运动强度，再辅助一些力量训练）。室内长期温度恒定，没有对身体时冷时热的轻度刺激。

二是因为社交压力，很晚还在大吃大喝，刺激胰岛素分泌，抑制内生的美骆托宁和生长激素分泌，入睡困难，或者睡眠浅，这样第二天更加困倦，形成恶性循环。

三是因为工作压力，无法控制自己的时间安排，不能在十点之前按时入睡，经常要担心各种琐事和截止日期。

四是根本不理解，或者拒绝理解这种结构性困境的机制，因此盲目接受周围人用药的建议，以为药可以解决所有问题，而不彻底从改变工作和生活方式入手。这样长期在治标不治本的陷阱里疲于奔命。

# 为了健康要集中注意⼒活在当下

加州⼤学旧⾦⼭分校教授 Elissa Epel 调查了硅⾕ 239 位，五⼗岁以上的，教育程度⾼，⽇常压⼒小的妇⼥。她发现⼼不在焉，注意⼒不集中（mind wandering）的⼈，其端粒（telomere）⻓度⽐正常⼈短 200 base pair（碱基对），等价于衰⽼程度多四年。

为了健康的⽣活，要集中注意⼒，活在当下，有⼈建议：

1. 多做瑜伽之类的冥想⼊静的运动。
2. 减少看电⼦邮件、短信、微信和朋友圈的频率，减少外界噪⾳的⼲扰。同时试图做很多事（multitasking）的⼈，DNA 端粒缩短的速度，和衰⽼的速度容易加快。

不快乐的⼈通常会⼼不在焉，因为他们⽆法活在当下，所以容易去想⼀些别的事情来逃避现实。

# 尽量拒绝和⽆视外界试图给你的时间压⼒

平常七点多钟早起，因为要把小孩叫起来，准备吃早饭上学，要赶时间，这种感觉是有些不舒服的。但同样是周末，早上七点多很⾃然地醒了，出去爬⼭，就没有这种不爽的感觉。看来不爽的本质，并不是因为睡不了懒觉，而是因为压⼒来⾃外部，猜测是⾝体分泌了太多⽪质醇（Cortisol），因此不爽。

但如果要做的事情是内在驱动，而没有明显迫切的外在压⼒，则⼼情舒畅很多。而⻓时间过多⽪质醇，必定带来⾼⾎压、⾎管斑块，和各种⼼⾎管疾病。

旅⾏赶⻜机，也常常有这种不爽的感觉。看来保持健康的⼀个重要⽅法是：尽量拒绝和⽆视外界试图给你的时间压⼒。

# 保护颈椎

我夜观天象，移动互联⽹的普及将导致颈椎病的普及和年轻化。颈椎病会带来各种并发症，严重的甚⾄可以导致瘫痪。唯⼀的防护⽅法就是节制⼿机的使⽤，积极锻炼颈部肌⾁。

# 如何防⽌久坐

解决久坐屁股疼的根本⽅法还是少坐。即使部分时间坐平衡球，还是觉得屁股肌⾁不舒服不⾃然。跑步可以解决腰酸背痛的问题，但是对于屁股疼似乎没有帮助。

有些商家卖那种可以调节⾼度站⽴办公的桌⼦ standing desk。但这种家具的问题是：体积太⼤，太臃肿，组装⿇烦，价格也动撤⼏百美元。

后来意识到最简单的⽅法，是把⼀堆书叠在桌⼦上，把⼿提电脑放在这堆书上，站着看电脑上的内容。好处是⾼度可以随时⾃⼰调节。站累了可以重新坐下来。⾮常灵活，也⽆需添置任何家具。

如果需要更专业化的解决⽅案，可以在亚⻢逊上买⼀个叫做 standing desk converter 的东西，价格只有⼋⼗美元左右，⾼度可调最⾼到 40 厘⽶左右，⾯积 72x43 厘⽶，上⾯可以放不少东西，而且完全不需要组装，买来就可以⽤。

改成这种学习⽅式后，屁股再也不疼了。

很久以前做程序员时，⿏标⽤多了后，右⼿的小臂会疼痛，然后把⿏标放到左边，⽤左⼿来控制，再左右切换，结果最后两只⼿臂都疼，⼏乎要到那个所谓腕管综合征（carpel tunnel syndrome）的边缘。最后解决的⽅法，是彻底不做程序员了，然后这个问题⾃然消失。

⼏年前开始，坐在电脑前⾯⼗分钟以上，屁股就会开始有些疼，换过各种椅⼦，但是都不能完全解决问题。于是开始⽤那种可以升降的办公桌，部分时间站着看电脑；但站久了腰⼜会感觉酸，还是得回去坐在椅⼦上；所以部分时间选择躺在垫⼦上听视频⾳频。同时略微尝试了各种瑜伽的放松腰椎的动作，但感觉效果都不是很明显。

跑步、游泳等运动⽅式，对解决屁股疼和腰酸的问题，也没有特别明显的效果。但坚持⻓跑后，肩酸背痛的问题则确实彻底没了。

前⼏天发现新的办法，就是吊单杠（dead hang），有拉伸腰椎的作⽤，吊⼏⼗秒后，腰椎会有极为酸爽放松的感觉，⽴竿⻅影，极⼒推荐。但受器材场地和时间限制，也不可能随时去吊单杠。

于是发现跪坐是另外⼀个好的选择，可以做到看电脑时腰椎基本没有压⼒，完全放松。但必须在地板上叠放瑜伽垫和软的坐垫，缓解膝盖部位的压⼒。但跪坐久了，脚踝、小腿⾎液循环还是受到压制有不良后果，而且对膝盖还是有潜在的危害。

所以现在基本采⽤「跪坐-站着看书-躺着听书-再穿插⼀些吊单杠和其它运动」之间不断切换，来维持脊椎的健康。希望维持这种「基本不坐在椅⼦上」的⽣活⽅式⼀到两个⽉，臀部肌⾁可以彻底放松恢复，然后就可以在「坐在椅⼦上-跪坐-站着看书-躺着听书-其它运动」之间不断切换。

翻了⼏本关于脊椎健康的书，感觉做这⽅⾯的医⽣绝对是个铁饭碗。年龄越⼤，腰背有问题的病⼈越多，完全不⽤担⼼没市场。而且每个⼈腰背出问题的机制和症状千差万别，所以很难有⼀个统⼀标准的解决⽅案。这就意味着，⼊了这⾏，就不⽤担⼼少数[[垄断，稀缺和财富的关系|垄断]]者把整个市场吃掉。

「这世界有两种⼈，背痛的⼈，和即将背痛的⼈」:)

据说 95% 以上的⽼年⼈，迟早都会遇上椎管狭窄（spinal stenosis）的问题。椎间孔狭窄会压迫到脊髓神经，导致上下肢疼痛⽆⼒，严重时会⼤小便失禁。因为这个问题本质是年龄增⻓导致脊椎⻣骼和组织的消耗劳损，⽬前还没有彻底根治的⽅法，只能缓解症状而已。

据说 80% 以上的⽛医都有颈椎和腰椎疼痛的问题，因为要⻓时间弯着腰给病⼈补⽛。

有了新的发现。意识到以前试过的椅⼦都不是那种真正有腰部⽀撑的⼈体⼯学椅 ergonomic chair（这个技术现在⽐九⼗年代⾼级多了），所以坐的时候腰部肌⾁会疲劳，这也会导致站⽴看书的时候腰部也容易疲劳。以为屁股疼是梨状肌的问题，但本质其实在腰。换了这种椅⼦，腰不酸了，屁股也没那么疼了。

---

最近在研究久坐或者开⻓途⻋屁股痛、腰痛的问题，意识到有两个思路上的问题。

⼀是本能地想解决症状，只想「扬汤⽌沸」，而没有去思考如何「釜底抽薪」。⽐如⽹上充斥着各种康复医师的视频，很多都是讲痛了之后，再如何拉伸放松肌⾁。但这种解决⽅法，练五分钟，只能缓解也许⼗分钟的症状，效率极低。因为你还是必须回去坐，稍不注意，⼜开始疼起来了。

第⼆个问题是，当你想釜底抽薪，解决问题的源头时，会误以为存在某种「正确的姿势」，而其它姿势都不正确。而实际情况是，没有所谓「绝对正确的姿势」，任何姿势保持时间过⻓，肯定某块肌⾁就会开始疲劳，如果⼀直给它过⼤的压⼒，不让它休息，它就会有点疼，甚⾄发炎，受伤。

正确解决问题的思路是：让⾃⼰能够快速地从⼀个姿势切换到另⼀个姿势，改变姿势后原来受⼒的肌⾁⾃然得到休息，过⼏分钟可以随时换回来，⾃然感到轻松舒畅。

现在把办公室内设置成可以迅速在「坐，跪坐，站，躺」这四种姿势之间基本⽆迟滞（2 秒钟之内）的切换，突然就意识到原来的腰酸屁股痛的困扰成了伪命题。

即使是有事被迫开⻓途⻋，除了调整座椅位置以外，也可以有其它改变体姿的⽅法。多带⼏个不同的坐垫、背后的靠垫，甚⾄小孩⽤的狗熊恐⻰之类的毛绒玩具，垫在⾝体不同的部位，不断切换。核⼼思路就是不要让某⼀块肌⾁持续⻓期受⼒，在切换改变姿势的过程中获得休息，疼痛的问题⾃然缓解。
