# 弱关系的重要性

摘要: 弱关系的好处，需要⻓时间建造，培育，然后⾃发涌现，有很⼤不确定性。但当其涌现之时，它可能⽐强关系带来的好处⾼⼏个数量级。这就是所谓的意外好运⽓ serendipity。这就是反脆弱。

最近⼏天阅读了 Niall Ferguson: *The square and the tower* 和 Richard Koch: *Superconnect* 两本书，颇有共鸣，有感而发。

1/ ⼈际关系分强关系（家⼈亲戚，好友，同学）和弱关系（⼀⾯之缘，点头之交，甚⾄⽹上神交）。

2/ 由于我们和强关系的朋友拥有类似的背景 / 经历 / 环境，反而彼此之间更难增加新的价值。而弱关系⽐强关系有更⼤概率带来新知识、新机会、创新。

3/ 弱关系是连接不同社群的重要桥梁，是促成信息的病毒式传播的关键所在。

4/ 缺乏弱关系的⼈，观点视野⾮常狭隘，缺乏对其它不同⽂化 / 背景的社会的理解。⻓期不利于其⽣存。

5/ 如果没有弱关系，我们就都变成各⾃独⽴的，完全分割的部落。

6/ 最有价值的弱关系，是那些可以连接你和其他⼤型社区的桥梁型的弱关系。

7/ 拥有很多弱关系，使我们智⼒上更加灵活，⾃由。更能理解不同的思维框架。

8/ ⼈的本性总是过分使⽤我们的强关系（家⼈，朋友。同事 / 同乡），而很少利⽤我们的弱关系（点头之交）。

9/ 有些弱关系，你以为他帮不了你，但是他可能会认识别的⼈，给你提供完全意想不到的帮助。

10/ 培养弱关系，要⾸先证明你⾃⾝有价值有实⼒，要不断积攒信誉，要有意愿理解他⼈的⻆度和思考框架，这样才会有实质性的沟通和价值交换。

11/ ⼀个简单的数学模型：假设⼀个弱关系对你有帮助的有效性，是强关系的三倍；那么弱关系，通过他的弱关系的⽹络，给你提供帮助的有效性，就是强关系的九倍。

弱关系的缺点是对⽅帮助你的意愿不如强关系的朋友，假设这个⼏率是强关系朋友的三分之⼀；但是数量上，弱关系的朋友可能是强关系的⼗倍甚⾄更多，而弱关系朋友的弱关系朋友，可能数量是强关系的百倍之多。

所以弱关系的朋友虽然和你不亲近，但是因为他的⽹络数量更⼤，和你互补的有效性⼏率更⾼，整体上对你的价值，可能超过强关系⽹络两个数量级之多。

这就是⽹络边缘的巨⼤⼒量，弱关系像⼀座座桥梁，使我们接触的边界更⼤，可以发挥的潜⼒越⼤。

12/ 做⽣意的⼈常有抱怨，都是陌⽣⼈让⾃⼰赚钱，而原来的强关系亲朋好友帮不上忙，于是感叹世态炎凉。这可能是⼀种认知的错觉，因为陌⽣⼈的需求和你的价值，互补匹配的概率⽐亲朋好友要⼤很多。

13/ ⼈口众多，产业多样化的⼤城市区，弱关系的匹配可能性和⼈口数的平⽅成正⽐。⼤城市⼈口聚集区，和小镇的差别，类似多细胞⽣物和单细胞的差别。因为交通拥挤和房价⾼昂而逃离北上⼴的⼈，最终⼤多还是会后悔的。

14/ 弱关系本⾝也是⼀个动态的概念。弱关系⽤多了，社群结构变了，原来的弱关系就变成强关系。

15/ 许多⼤公司⽆法接受新技术环境挑战的⼀个关键因素，在于其运营结构严重依赖于现有的强关系。即使⾯临环境巨变的威胁，公司⽂化上缺乏机制去割舍强关系，主动构建弱关系。

16/ 弱关系可以看成是我们和外在客观环境的⼀个纽带，帮助我们保持和环境变化的同步，随时改造⾃⾝，以适应环境。

17/ ⽣物界的有性繁殖，可以看成是通过弱关系的组合，来增加多样性，⾯对多变的环境的⼤⼤提⾼⽣存能⼒的有效⽅式。而近亲结婚的后代，遗传病概率⼤，彰显强关系的弱点。

18/ 弱关系帮你找到更好的事情去做，强关系帮你把现在的事情做得更好。

19/ 弱关系以你意想不到的⽅式，帮你创造价值。强关系则帮助你在现有的范式下，捕捉锁定价值。

20/ 弱关系的好处，需要⻓时间建造，培育，然后⾃发[[涌现]]，有很⼤不确定性。但当其涌现之时，它可能⽐强关系带来的好处⾼⼏个数量级。这就是所谓的意外好运⽓ serendipity。这就是[[不对称性，凸性和反脆弱|反脆弱]]。

21/ 强关系类似神经⽹络的宽度（知识的深度），弱关系类似神经⽹络的深度（知识的⼴度）。⽹络的深度数量增加，各种可能性指数型的增加。深层神经⽹络技术的突破，导致了当下的⼈⼯智能技术的⻜跃，这是数学上的必然。
