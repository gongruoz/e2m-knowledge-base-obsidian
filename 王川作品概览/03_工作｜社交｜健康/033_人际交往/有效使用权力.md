# 有效使用权力

摘要: 人性的本质就是「幕强」和「逐利」。 对外人需要高度警惕的是：狐假虎威式的「假强」和实为陷阱的「假利」。对自己需要注意的是：做个有用的人，始终能有效抗击外界的潜在侵害。

# 有效地使用权力更能扩充权力

「权力不是一个用完就没有了的稀缺资源。... 使用权力，就是对外发出信号，你有权力；因为人们被权力所吸引，你行使权力越多，证明你很强大，你就会积累更多的盟友。所以有权就要用，也许要用的比人们想象的更多。有效的使用权力，更能扩充权力，而不是耗尽它。」

「对于那些想获取权力，尤其是处于弱势地位但想获取权力的人，打破规则，是唯一的理性的，可能的选择。」「规则一般都对现有的强者有利。...（事后）寻求宽恕，比（事前）寻求许可，要容易和有效得多。」

# 人性的慕强与逐利

人性的本质就是「幕强」和「逐利」，这种潜意识在很多细微行为中都暴露得淋漓尽致，必须高度尊重。 对外人需要高度警惕的是：狐假虎威式的「假强」和实为陷阱的「假利」。对自己需要注意的是：做个有用的人，始终能有效抗击外界的潜在侵害。

# 对抗优先

（重要的事情）如果只能选择对抗或者妥协（默认接受别人的条件），那么优先选择对抗（默认要以我为主，要对方接受自己的条件），一般来说最后结果会更好一些。
