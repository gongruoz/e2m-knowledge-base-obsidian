# 放弃对世界的一厢情愿

摘要: 自说自话的人是可耻的，自说自话而不自知的人是可悲的。
一个好的沟通者如果不能把注意力完全聚集在对方身上而是自说自话，就很难有效影响对方的决策。

世间很多悲喜剧和⿊⾊幽默，都来⾃我们执着地⼀厢情愿地理解世界，或者换句话说，固执地要让世界接受⾃⼰错误的思维模型，固执地拒绝改变⾃⼰而希望世界为⾃⼰改变。⼀厢情愿在⼈际交往、谈恋爱、国际政治、投资、销售，等等各个领域屡⻅不鲜。

改变⾃⼰的⼀厢情愿，是最困难的，也是最容易的。困难是因为每个⼈都有强烈的⾃恋情节，觉得⾃⼰特殊，觉得世界要应该去适应他 / 她，而且很多⼀厢情愿的理念⾮常有诱惑性，或者让⼈觉得有美感，或者迎合了⼈的⼀些底层的情绪，尽管它是⼀种掩耳盗铃的⾃我欺骗。

容易是因为意识到，⼀旦放弃⼀厢情愿，以⾼度的现实主义不断调整对世界的认识，指导⾃⼰的⾏动，路会越走越宽，越来越容易。

⼀厢情愿的例⼦之⼀，是以为我们对别⼈好，别⼈就⼀定会回馈。但客观现实是，指导⼈们⾏为的标杆，是未来你对他有什么好处。⽆原则地释放善意，是⾃⾝资源的巨⼤错配。如果因为别⼈不帮你，对别⼈进⾏忘恩负义的道德指控，是⽆效⽆益的。让⾃⼰未来始终有⽤有价值，才是正解。

这⾥引⽤美国⼀位作家 Robert Greene 的著作 *"The 48 Laws of Power"*，直译是「权⼒的四⼗⼋个法则」，⾥⾯第⼗三条法则是，「当你寻求别⼈帮助的时候，要从对⽅的⾃⼰利益出发来引导，而不是乞求他们的仁慈或者感激」。

书中讲了⼀个历史故事，大概在公元前 433 年，希腊半岛上两个岛国要⼲仗，⼀个叫 Corcyra，⼀个叫 Corinth。两家都派说客寻求与雅典结盟。因为他们知道，只要与雅典结盟，就可以轻松⼲倒对⼿。Corcyra 的使者对雅典⼈说，虽然我们两国以前没啥来往，但是我们也有强⼤的海军，如果我们结盟，可以对斯巴达，我们共同的敌⼈，形成强⼤的威胁。Corinth 的使者，则不断强调他们和雅典的传统友谊，不断提醒雅典他们过去为了雅典做了哪些好事，送去哪些利益。不断强调忠诚，不要背叛过去的⽼朋友。

等两国使者走后，雅典决策者投票，⼀致选择和 Corcyra 结盟，抛弃 Corinth，因为这样可以对斯巴达制衡，符合雅典的利益。

这⾥引⽤德国哲学家叔本华（1788-1860） 的⼀段话：「⼤部分⼈彻头彻尾地⾃以为是，除了⾃⼰以外，别的事都不会让他们感兴趣。他们胡喷⼀通后，总是⻢上思考⾃⼰的事情。随便提及任何对他们⾃⼰个⼈可能产⽣⼀丁点影响的事情，哪怕⾮常遥远，也会吸引他们全部的注意⼒。」

所以我们寻求外⼈帮助，⼀定要放弃⾃⼰⼀厢情愿的⻆度，要从对⽅⾃⼰利益，设⾝处地的考虑，这样才能有效影响对⽅。即使是看似最有⼒量的⼈，他也有顾忌，也有利益诉求。如果只是乞求别⼈的仁慈和善良，多半会被别⼈当可怜⾍，瞧不起，不会被理睬。

再加⼀句我的总结：不仅要让⾃⼰有⽤有价值，而且要让很多⼈都知道认可⾃⼰有⽤。只要你有⽤，只要很多⼈知道你有⽤，就不愁在未来找到各种各样源源不断的合作者。同时其他⼀些不相⼲的旁观者在思考是否和你建⽴合作的关系中，也会因为这个因素，会对你有更多尊重。从这个⻆度看，那些⽢于默默⽆闻，从不利⽤社交媒体来宣传⾃⼰的⼈，⽩⽩丧失了发展⾃⼰事业的⼀个重要⼯具。

⼀厢情愿的第⼆个例⼦，就是很多⼈被灌输了⼀个执念，就是只要埋头努⼒⼯作，就肯定会有收获，然后往往⽤「对得起⾃⼰」这种说词来掩耳盗铃。但实际情况是，我们常常看到，创造价值，和捕捉价值，是两个完全不同的概念。⽐如说，推特作为⼀个平台，让很多⼈之间建⽴连接，做成⽣意，创造很⼤价值，但推特作为平台，居然在这个过程中没有捕捉到什么利益。而它的股价，2013 年底上市当天收盘在 42 美元，2019 年底收盘价 32 美元，市值只有脸书的 4%。但是我个⼈作为⽤⼾，认为推特作为⼀个平台，对社会的贡献，创造的价值，是远⼤于脸书的。

还有苹果⼿机的崛起，当时它只占有市场份额的 4%，但是却占有市场利润的 50%。⼤约五年前，我在我的⽂章「软件吞噬世界」⾥⾯举了很多例⼦，平台级的软件公司，单个员⼯的平均收⼊远远超过硬件公司。实际上半导体硬件公司，进⼊的⻔槛是⾮常⾼的，芯⽚设计需要电机⼯程的很多理论与⻓期⼯程实践知识，很多需要博⼠学位。但是他们很多资深的硬件⼯程师，可能收⼊远低于在某些软件公司⽐如⾕歌、脸书、Netflix 赚⼤钱的，学历不⾼，⼆⼗多岁的软件⼯程师。

对于这个看似不公平的现象，我们简单抱怨是没有⽤的，必须抛弃⼀厢情愿，深度思考底层的科技领域的权⼒架构，价值捕捉的机制，把⾃⼰定位放在顺应事实真相，让⾃⼰利益最⼤化的那⼀边。而不是⼀厢情愿，以为⼲活越努⼒，⾃以为的创造价值越多，就⾃然可以成功。

引⽤德国哲学家尼采在 *「超越善恶」* 这本书第 39 节中的⼀段话，他引⽤⼀个法国⼈的话说：「要成为⼀个好的哲学家，必须不形于⾊，思维清晰，不存幻想。⼀个发了⼤财的银⾏家，拥有⼀种可以在哲学领域有所发现而必需的品质：就是实事求是，看清问题本质 (seeing clearly into that which is)。」换句话说：看到什么就是什么。不要主观地，添油加醋地，⼀厢情愿地去想象，⼀厢情愿地去意淫。

关于⼀厢情愿的第三个例⼦，和国际关系有关。这⾥特别推荐⼀本书，作者叫徐弃郁，书名叫做《脆弱的崛起：⼤战略与德意志帝国的命运》，2011 年出版。我是从哲学的⻆度来学习阅读这本书的，⾥⾯很多分析总结让⼈拍案叫绝。我稍作了些整理修改摘录下来。

徐弃郁：「历史规律还是给⼈的主观能动性留下了充⾜的空隙，偶然性是其中的重要部分，而⼤战略的任务就是尽可能地顺应‘规律’，同时尽可能地利⽤‘历史的空隙’。在威廉德国，俾斯麦深刻理解这⼀点，并且随时准备接受⼀种不完善的，甚⾄是不确定的结果。但他的继任者却正好相反，事事追求确定性，同时⼜过于强调必然性。这种哲学层⾯的差异是俾斯麦下台后德国的⼤战略迅速⽡解的重要因素。而到了后期，德国领导⼈对必然性的强调更是发展到了⼀种偏执，越来越坚信⼤战‘不可避免’，⽽⼀系列为‘不可避免’做的准备⼜使得⼤战真的‘不可避免’。」

俾斯麦论⼀厢情愿：「出于纯粹主观上的原因擅⾃⼲预历史的进程，就好⽐摇落不成熟的果实。在某种形势正在变化的时候能进⾏等待，这种能⼒是现实政治的迫切需要。」

在俾斯麦看来，⼤部分德国⼈的性格缺陷——不能等待事情的发展，⼀厢情愿地坚持事先对形势有⼀个⼗分明确的判断。这种缺陷可能还包括：⼀厢情愿地过于要求精确和讲究逻辑。对于个⼈来说，事事要求清晰、符合逻辑未必完全能做到，而对于⼀个国家对外战略来说则可能是场灾难。

俾斯麦下台后德国外交政策⼀厢情愿的第⼀个例⼦：俾斯麦的很多幕僚不理解他的外交政策的很多看似⾃相⽭盾、不清晰的地⽅的妙处。他们⼀厢情愿地要求清晰，他们认为德国和俄国秘密签订的再保险协议⾥⾯，德国没有获得什么明确简单的利益，应该确⽴⼀条更加简单、更值得尊敬的外交新路线。俾斯麦 1890 年辞职下台不久后，1890 年 6 ⽉俄德「再保险」条约 (Reinsurance Treaty) 失效后，德国拒绝续约，并且对俄国清晰地表达⽀持奥匈帝国在⿊海海峡问题的⽴场，这样变成事实上被奥地利绑架。

德国主动背起了⽀持奥匈帝国的全部责任，德奥同盟内的主导权开始发⽣微妙变化。德国新决策者的做法不仅改变了俾斯麦的对奥政策，而且还相当于亮明了德国将全⼒⽀持奥匈这⼀底牌。这样，⽀持奥匈就完全成为德国的义务，俾斯麦与英国之间为此⻓达 20 年的相互「推卸责任」的默契就此画上句号。另外，当奥匈已经摸清德国⽀持是确定⽆疑的时候，德国实际上也失去了利⽤同盟为杠杆来约束奥匈的能⼒，同盟关系中「弱者决定强者」的奇特现象在此后持续了⼆⼗多年，直接导致 1914 年⼀战爆发。

德国外交政策⼀厢情愿的第⼆个例⼦：⼀厢情愿地着急讨好对⽅，热脸蹭别⼈的冷屁股，损失了实际利益，更重要的是，反而丧失了和对⽅以后讨价还价的筹码。俾斯麦下台后，德国政府急于提升和英国的外交关系。英德正在进⾏的殖⺠地谈判似乎为此提供了⼀个很好的机会。1890 年初两国开始关于⾮洲殖⺠地的谈判，主要内容是英国⽤其在北海的赫尔果兰岛交换德国在东部⾮洲的两块殖⺠地。英国保守派的索尔兹伯利政府与俾斯麦的这场谈判进⾏得⽐较艰难，到俾斯麦下台时仍处于僵局。在德国新的决策者看来，这恰恰是⼀个向英国表⽰友好、拉近两国关系的好机会。

但是德国对英国很快犯了外交中的两个⼤忌：「第⼀是在事态并不紧急的情况下急于达成某种协议，而不是充分利⽤谈判过程为⾃⼰谋求利益塑造有利态势。第⼆，作为⼀个⼤国在事态根本不紧急的情况下急于向另外⼀个⼤国讨好输诚，甚⾄还主动考虑对⽅国内政治需要」。从条约的字⾯上看，德国已经明显吃了亏。按照当时欧洲各国的看法，⽤东⾮两块富庶的殖⺠地换取北海中的⼀个岛屿是⼀次愚蠢的交易。而从英德两国深层次的战略关系来看，这个条约对德国的负⾯影响更⼤，主要是进⼀步破坏了英德之间战略需求的平衡。然而到 1890 年时，德国对俄奥政策的变化使得德国主动背起了⽀持奥匈的「重任」，所以在⿊海海峡问题上英国根本不需要再为德国的⽀持付出任何代价，英德之间的战略需求平衡开始发⽣倾斜。

德国新的决策层对英德友好的追求完全属于「⼀厢情愿」。德国是⼀个正在崛起的⼤国，而英国则处于世界霸主地位，这样的两个⼤国之间必然存在很深的结构性⽭盾，「紧密合作」甚⾄「共同治理」往往只是在某些具体领域，而不太可能是全⽅位的。这种崛起与霸权的关系，⼀般只能通过相互借重、相互畏惧、相互制约来保持⼀种复杂的稳定。因此，在德国⼀味向英国⽰好的同时，英国对德国的态度却没有变化。

1890 年俾斯麦下台后，索尔兹伯利对于新的德国领导⼈明显看不上眼。他在给英国驻罗⻢⼤使的信中写道：「我不愿意忽视我的德国朋友们明显的焦急情绪。但现在接受他们的建议是不明智的。俾斯麦已经走了。他们现在对付起来要容易得多，也令⼈愉快得多。但是他们缺乏那位⽼⼈那种卓越的洞察⼒。」这种机会英国⽆疑是要充分利⽤的，特别是要收回原先向俾斯麦政府做出的承诺，重新保持⾃⼰的「⾏动⾃由」。

引⽤英国历史学家⼽登克雷格 (Gordon Craig) 的话：「如果存在⼀种更简单的道路可以实现俾斯麦的⽬标，这位宰相⽆疑会采⽤的，因为他不是崇尚复杂才使⽤复杂⼿段的⼈。但当所有的简单化道路都是危险的和⾃我否定的时候，俾斯麦发现必须走⼀种曲折的道路。这样做的代价不仅仅是给后⼈带来困惑，甚⾄使他最亲近的合作者也迷惑不解。」

所以当我听到⼀些朋友侃侃而谈「⼤道⾄简」的时候，我知道，他们可能会因为顽固地⼀味追求简单，以简单为⽬的，而重复前⼈的那些⼀厢情愿的挫败。

⼤道⾄简的⼀个⻆度可以理解为后端复杂，但对外的 API 简单。但⼀些⽆知的懒汉，偷换概念，想不劳而获，⾃⼰后端简单，没什么货，也妄想前端的 API 能简单。
