# ⾃⼰的知识体系越丰富，越能产⽣跨领域的连接

# 帮别人与外部资源建立独特连接

人或者公司增加价值的一个角度是帮别人或者公司，和外部资源建立某种独特的连接：这个独特可以是唯一，或使用最方便，或速度最快，或可信度最高，等等。

没有独特的维度，则没有大的价值。

# 社交媒体的正确使⽤⽅法

1. 不浪费⼀秒钟时间和知识结构相差太⼤的⼈去解释/讨论。你没有义务也没有这个精⼒。对任何不友好评论，迅速拉⿊。
2. 通过公开展⽰你的思考，来寻找在知识结构，兴趣或技能上，可能与你产⽣互补作⽤，或者 1＋1 > 2 的效应的朋友。公开展⽰⻓期留存的⽂字记录，效率最⾼。
3. 分享思考时，⼀定要遵循⾃⼰求知求真的兴趣去摸索，而不是违背⾃⼰内⼼去迎合外⼈。有⻓期价值的兴趣不是吃喝嫖赌吹拉弹唱这些表⾯的东西，而是：某个东西真实底层运作机制是什么？ 为什么某⼈会在这件事上胜出？ 为什么某⼈屡屡失败却还是不断重复错误？ 为什么某个系统可以产⽣结构性优势？遵循⾃⼰内⼼深处真实的兴趣，⼀⽅⾯会保持强烈的⾃发动⼒，⼀⽅⾯会聚合类似的与你有同样真实而强烈兴趣的朋友互动交流。很多表⾯的浮光掠影的泡沫，存在⼤量欺骗性，而且极不稳定。但研究底层原理性的东西，则可以把握事物稳定的本质，而且容易⼀通百通，发现很多不同领域有价值的应⽤。
4. 成年⼈只能被筛选，不能被改变。虚拟世界可以接触到的⼈数⾄少⽐物理世界⾼四到五个数量级，筛选效率也要⾼⾄少⼏百倍，⾼下⽴⻅。

# 识别杠精的简单⽅法

社交媒体是⼀个获取多维度信息的⾼效渠道。最有益的交流，来⾃于外⼈告诉你的从未听说的新的维度的信息。

但社交媒体的最⼤陷阱是被杠精纠缠浪费时间。杠精的特点是以争论对错和⾼下为导向，而不是以交流客观数字与信息为导向。

识别杠精的简单⽅法是：如果你还要思考⼀下他是不是杠精，那他⼤概率就是了。

宁可错拉⿊三千，不可与⼀个杠精纠缠。否则他会以他独特擅⻓的⽅式把你带到沟⾥。

# 增加和外界「⾼信任度的连接」

真正有可能获取最⼤利益的⼈是在技术和商业模式两边⾃由游走的⼈，能够理解技术具体如何改变和发展新的商业模式，能够从商业模式的⻆度理解技术的哪个维度更重要。

这也是 Edge of chaos (混沌边缘) 的⼀个体现吧。商业模式本质就是定义「⼈和⼈之间如何利益交换」，简单的买卖关系⼤家都好理解。

⼀旦涉及到很多不同地⽅的不同⼈，利益交换可能要跨越⼏个不同的实体，跨越稍微⻓⼀点的时间，运⽤不同的媒介，就很容易把⼈搞糊涂了。利益交换的迂回，往往是常态，因为这样阻⼒最小。

增加和外界「⾼信任度的连接」，也就增加了「利益交换」的新的路径，也就指数级增加了新的路径组合，新的商业模式的可能性。

# 提⾼⾃⾝的流动性

世界最终是靠流动性连接成⼀个共同体的。

流动性越⾼，交易摩擦和迟滞越低的系统会⾃然而然地集聚整合而成为⼀个共同体。

整合是个双赢的过程，在这个共同体内任何⼈花钱和赚钱的效率都是最⾼的。

这个整合越发和物理距离没有关系。你和邻居近在咫尺，但是如果缺乏共同语⾔和互补的需求，那就不可避免地⽼死不相往来。

就像更多⼈慢慢更愿意在亚⻢逊上购物，也不愿到附近小店买东西，因为选择更多，购买更⽅便简单，更快，品质服务更有保障，等等。

不要小瞧流动性的创新。它通过标准化的合约，把更多个⼈和经济体吸⼊到这个共同体内，⼤家分摊费⽤和⻛险，共同提⾼效率。虽然这个创新的发展过程中会有各种骗局和曲折，但整体⽅向是⽏庸置疑的。

所以投资的⼀个视⻆，是掌握世界上流动性最⾼的系统内的最稀缺的资源。流动性是建⽴在信任的基础上的。从个体⻆度而⾔，信赖你的⼈有多少，你的流动性就有多⾼。而这个数⽬超过某个临界点，就会形成品牌效应，流动性产⽣指数级的跃迁。

就像张⼤千的画作，和⽆名画家的画作，即使看起来⼀样，但流动性完全不⼀样。

流动性⾼的世界，常会出现⼀些看似不符合逻辑的荒唐现象。⽐如已经宣布破产的赫兹租⻋公司，股价从五⽉底的五毛钱涨到六⽉⼋号的五块五。既然流动性这么热情，就不要辜负⼤家的好意，于是赫兹公司决定成⼈之美，宣布要再发⾏两点五亿新股。宁要流动性⾼的草，不要没有流动性的苗，诚不我欺也。

普通⼈乞求在他⼈制造的流动性体系中分⼀杯羹，这是个拥挤而越发困难的游戏。互联⽹提供了⼀个⾃⼰创造新的流动性的⽆限可能。

流动性本质是更安全，更便宜，更快，规模更⼤的对外连接管道。流动性⽹络越⼤，才能更科学⾼效地定位⾃⾝⻆⾊。流动性⽹络越小，则⾃然而悲催地成为井底之蛙。

# ⽣态和关系⽹复杂的优势

⽣态和关系⽹复杂的玩家，有这样⼀个优势：就是不需要在任何单笔交易的毛利润 (Gross margin) 上锱铢必较，而可以⽤相对慷慨的条款与很多潜在合作伙伴结盟，因为这种结盟可以给他带来⻓远的，持续的间接好处，⽐如降低单位获客成本，提⾼实际运营利润率 (operating margin)。

更重要的是，这种潜在优势会随着其⽣态规模扩⼤而增加，强化。

在不过多消耗⾃⾝带有稀缺性的瓶颈资源（⽐如时间）的前提下, 不断主动扩⼤和外界合作的规模，是提⾼⾃⾝利润率和效率的⼀条可以真正⻓期持续的捷径。

# 论 1% 和 99%

1/⼀个贴上同⼀个标签的群体内，顶尖的1%和其余的99%，是特性完全不同的个体。⼆者可以相差⼗万⼋千⾥，差距胜过艾滋病和艾滋海默症的分别。

2/ ⼀个群体的宏观特性，往往是由顶尖的1%所决定。顶尖的1%， 会在群体内外⾃动地被⼴泛宣传，⽐如优秀的个⼈/成功投资退出的项⽬，等等。

3/ 但观察者可能会产⽣错觉，爱屋及乌，把群体的其他99%和顶尖的1%混淆起来。每个本属于99%的创业者都觉得⾃⼰是下⼀个脸书，⾕歌，阿⾥，腾讯 等等。最后的结果往往是深深的沮丧。

4/ 群体内平庸的99%会依靠群体顶尖的1%的⼈带来的光环，利⽤群体的标签，到外⾯骗吃骗喝骗炮，闹出不少⿊⾊幽默的故事。

5/ 第⼆个错觉是，不同时代/不同环境下，某个群体内的顶尖的1%， 可能是特点完全不同的个体。 顶尖的1%之所以顶尖，个⼈努⼒固然重要，时运也占了很⼤的⽐例。

6/ 群体的标签包括某个学校的校友，某个公司/机构的前员⼯，某个新兴⽕爆的⾏业等等。这些标签在某些场景下，有⼀定指导和筛选的作⽤。但是如果不花时间透过现象寻找本质，很难抓住真正的1%，而会把时间精⼒浪费在各种99%的平庸的事物上。

7/ 很多观察者因为接触的都是那平庸的99%， 希望而来失望而归，因此很⾃然地得出简单粗暴的结论：「某某标签的⼈/公司都是傻⼦，骗⼦，等等」。但真相远⽐这复杂得多。

8/ ⼈⽣的⼀⼤悲剧，是99%的⼈拿冒尖的1%的⼈的似是而⾮的，部分靠运⽓的经验和轨迹，（而不是结合个⼈的特点）指导⾃⼰的⾏动计划，结果往往邯郸学步，弄了个四不像。

9/ ⼈⽣的第⼆⼤悲剧，由于不同的经历和体验，接触到某个群体顶尖的1%的观察者，和其余99%的观察者，对这个群体会有截然不同的结论，然后会为此吵个不停。其实他们只是看到同⼀个事物的不同侧⾯而已。因为过去⽚⾯的成功或者失败的经验，而对此群体狂热地看好，或者嫉恶如仇般地坚定看空，都是同样幼稚可笑的。

10/ 真的猛⼠，不为简单的标签所蛊惑，不试图提前预判顶尖的1% ，歌舞升平时不得意忘形，哀鸿遍野时仍看到希望所在。然而群体的情绪⼜常常为庸⼈主导，以粗暴的逻辑，和情绪化的宣泄，来洗涤⾃⼰的⽆知，重复演绎出各种⼈间悲喜剧。

# 如何做⼀个超级连接者

最近读了 Scott Gerber 的 "Super connector"，和 Erica Dhawan 的 "Get big things done： the power of connectional intelligence"，有感而发。

1/ 和外界建⽴⼴泛和有价值的关系，是事业成功的超级助推器。但连接绝不是到处发名⽚，微信或 LinkedIn 加好友。要建⽴有效的连接，⼈⾸先要有⾃知之明。

2/ ⾃知之明的最重要⼀点是不要以⼰度⼈。这包括多个⽅⾯，不能以小⼈之⼼度君⼦之腹，也不能以君⼦之⼼度小⼈之腹。不能以穷⼈的消费价值观来揣测富⼈，反之亦然。不能以男性的视⻆价值观和⼥性沟通，反之亦然。

3/ ⼈的本性是习惯性从⾃⼰的⻆度和价值观看问题，很少主动从他⼈的⻆度看问题，理解他⼈的需要。许多让你困惑觉得不可思议的问题，其实换个⻆度，从别⼈的视⻆看，⾮常简单明⽩不过。但如果不能够跨过这个坎，学会从对⽅视⻆理解问题，完全沉浸在⾃⼰⼤脑臆想的泡沫⾥，就会犯各种低级错误。

4/ ⼤部分做销售的⼈，⼀开始都没有⾃知之明，想问题完全不是从听众⻆度来思考。这表现在上来就不断介绍吹嘘⾃⼰，⽤⾃⼰的语境来表达，而完全不去聆听理解听众的要求，不去思考⾃⼰是否真正能够解决别⼈的问题。

5/ 另外⼀个例⼦是，很多⼈完全没有任何⾃我介绍，就去要求不熟悉的⼈引荐⼯作，介绍资源，寻求投资，完全是⾃说⾃话。别⼈凭什么要这么做啊？

6/ 这种做法可以叫做「阿 Q 跪拜吴妈式」：⼤约在公元⼀九⼀零年前后的某⼀天，阿 Q 唐突地跪在吴妈⾯前，⾃说⾃话地表⽩，「吴妈，我想要和你困觉！」我们都知道后来发⽣了什么。

7/ 这种低级的连接⽅式，如果不彻底改正，效果差，效率低，只是⾃欺欺⼈。
