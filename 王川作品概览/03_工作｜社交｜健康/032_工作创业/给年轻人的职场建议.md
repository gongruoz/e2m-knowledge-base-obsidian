# 绕过传统机构，通过社交媒体实现个人主权

哈佛大学和很多其它有名的官僚机构一样，就是一个亮闪闪的牌子，后面有着无数官僚和南郭先生期望靠着这块牌子混饭吃。而且牌子后面的人员流动频繁，当机构需要有人挺身而出为一个错误决策承担责任时，很少有人愿意这样做，基本都是口惠而实不至。

与其给学校或其它机构（本质是一些你不认识以后也很难有交集的陌生人）捐款，不如对你身边给你各种服务的人慷慨一些。做诚实的商业，如果你赚的越多，就意味着你对社会的贡献越大。

给学校或其它机构捐款的人，其内心深处还是希望未来能够从此机构的网络中获得某种潜在回报，扩大自己的影响力。但实践上有操作瓶颈，而且你在别人建立的网络中，可以制定规则和挑选的余地并不大。

社交媒体和主权个人时代，意味着你可能绕过这些传统网络，自信地建立自己的新网络，并且精准高效地把你的慷慨送给开放世界里那些配得上的人。

# 追随自己的好奇心

如果只是为了最终赚钱而不享受过程的话，很多人面对各种意想不到的挫折，根本无法坚持下去。能够坚持下去的东西，本质都是过程当中有些难以描绘的细节，让你感到鼓舞，让你获得乐趣，而恰恰就是这些细节让你能够有远超常人的长时间坚持，最终在意想不到的地方获得突破，赚大钱只是一个附带的自然的产物。每个人的知识结构和兴趣都不一样，因此能够推动他们持续向前走的路径都不一样。相信自己的好奇心引导的路径，不要盲目模仿（很可能被媒体严重扭曲和夸大的）他人的路径。

# 社会经验是端对端训练

学校教育好比 hard code（硬编码）灌输各种规则和理念。在社会上打拼就好比 end to end training（端对端的训练）。硬编码的优点是开始可以有不错的表现，缺点是不够灵活，面对巨大变化时呆若木鸡，而且因为结构性缺陷无法调整去适应变化，存在隐形的天花板。

端对端的训练，缺点是开始表现比较粗糙，收集数据获得真实[[设计自己的反馈机制|反馈]]都需要成本和时间，进步开始比较缓慢。但一旦在数据收集的广度深度，和反馈的质量和速度上有所提高，训练的积累越过[[阈值|临界点]]之后，可以理解各种微妙的潜规则，能够应对复杂模糊的场景，进步加速，并能较快地适应环境变化，成长没有天花板。

不是所有的端对端训练，都可以获得好的效果。潜在障碍有：

1. 很多人收集的都不是关键的重要的数据，而是一些驴唇不对马嘴的不重要的东西。
2. 从收集数据到读取的过程摩擦太高，太慢。
3. 无法获得迅速反馈。
4. 反馈根本就是错的，或者故意误导。
5. 训练数据的广度深度都太低。

# 研究自己可以创造什么价值

不要抱怨什么世态炎凉，而是要研究自己在什么地方可以创造什么价值，可以解决什么问题，可以在什么样的市场寻找可以交换价值的对象。

这里面「市场」其实最重要，市场越大，问题越多样化和复杂化，你可以创造价值的方式方法也多样化。

# 让潜在合作者看到自己

让自己运气更好的关键，是增加自己的可组合性。让更多潜在合作者看到你，通过合作创造新的可能，以此为依托进一步接触更多的潜在合作者，不断螺旋式上升。

运气更好永远是个层层迭代的过程。以为孤注一掷，一锤子买卖，守株就能待到兔，是痴心妄想，浪费生命。

# 为什么⼤部分求职者的管理之道荒唐且低级

1/ 如果把个⼈的事业当成⼀个公司来看，⼤部分⼈找⼯作时，其管理⽅法实际上是⾮常荒唐低级的。

2/ 公司需要常年累⽉地做宣传，建⽴⾃⼰的品牌和商誉。但绝⼤部分专业⼈⼠没有这种意识，或是在此之上的投⼊的时间精⼒很少。以致于四五⼗岁了，要找新⼯作时，还要⼀次次口⼲⾆燥地解释证明⾃⼰。有品牌的公司和个⼈，⽆需任何解释，因为功夫平时已经做⾜了。

3/ 公司不断做销售，积累各种客户，⼀般都不希望单个客户的销售收⼊占⽐例太⾼，而导致过⾼的依存度。但打⼯者只依赖⼀个客户，⼀旦被解雇，收⼊来源⻢上断掉，有很⼤压⼒要迅速去寻找新客户。

4/ 市场的很多真实需求，实际上不是显性的，不会出现在招聘⼴告上的。换句话说，雇主找⼈，⼀般会找周围熟⼈推荐，找不到合适的，再会去打⼴告。如果只是通过公开招聘信息找⼯作，你看到的只是市场的部分需求（可能远不到⼀半）。

5/ 另外⼀种情况：潜在雇主 / 客户 / 合作伙伴，许多时候可能根本不知道⾃⼰想要什么，直到有⼀天他发现了你能提供的东西，正好对他有巨⼤价值。

6/ 如果有⻓期的宣传建⽴的品牌，常常会有客户⾃⼰找上⻔来，让你发现以前没有意识到的市场需求。不宣传⾃⼰，不对外探索，你永远不知道那些你不知道的市场（you don’t know what you don’t know）！

7/ 而当⼀个极强动⼒的⾼端客户找上⻔的时候，你就有能⼒根据你提供的巨⼤价值来收取⾼额的报酬，而不必再理会那些利润率较低，需求和你提供的东西不匹配的客户。⼆者的单位时间的利润率，差距可能有两个数量级以上。

8/ 因为平时没有积累，当打⼯者想出售⾃⼰的技能时，⼀没有⼤量客户可以选择，往往临时抱佛脚，机会主义地乱发简历，而这些简历⼤多被扔到垃圾箱⾥去了。

9/ ⼆是因为有时间压⼒要早做决定，所以很快把⾃⼰草草地以⼀个平庸的价格卖给⼀个平庸的雇主（客户），然后好了伤疤忘了疼，⼜回到当⼀天和尚撞⼀天钟的状态。

10/ 打⼯者最终还是在出卖⾃⼰的时间，⽆法将⾃⼰的劳动成果⼀份卖多次，卖很多年。因此其商业模式没有[[可扩展性|扩展性]]，限定了其利润率，也导致他没有时间和资⾦去对⾃⼰做各种战略投资，进⼀步提升宣传⾃⼰。

11/ 所以他们永远⽆法知道⾃⼰不知道的东西。They will never know what they do not know.

# 最⼤的⻛险是不⾏动

⼈们思考问题的时候，会有⼀个潜在的假设，就是⾃⼰⽬前的状态，默认的状态，是合理的。

任何改变默认状态的⾏为，即使有⼀丁点⻛险的概率，也容易被认为整体很危险，就会导致⼈们不愿意偏离⾃⼰的「默认状态」。这属于⼀种「不作为的倾向」（inaction bias）。

这种倾向，是好是坏，要具体问题具体分析，不可⼀概而论。如果⾃⼰对⽬前的默认状态很不满意，⾏动的收益远⼤于⻛险，当然要倾向于⾏动。

# 寻找价值链上你更能占据优势的位置

所有的决策，都是基于对未来的预测。未来本质是有很⼤不确定性的，如果未来发⽣变化，你也必须改变。你改变的速度，必须和未来的变化⼀样快。所以，对未来的感知和预测，⽐其它东西都更重要。

这⾥⾯有⼀个关键，如果你现在做的事，有任何⼈可以做得⽐你更好，成本低很多，那么你就应当迅速放弃现在做的事（不管暂时有多痛苦），而去寻找价值链上你更能占据优势的位置。

# 给年轻⼈的⼗点职场建议

最近有位年轻⼈向我咨询⼀些职场发展的问题，有点感触，总结如下：

1/ 不要怕适度冒险，不要太多顾虑。最坏就是丢个⼯作而已，最坏就是损失⼀两年的收⼊而已。⽣死之外，都是小事。为小事而焦虑，患得患失，不敢⾏动去追求⼤的机会，过⼗⼏年后再回头看，会觉得很可笑。

2/ 在⽐较不同职位时，优先考虑那些可以给公司增加收⼊的职位，所谓 profit center。避免那些后台打杂的，搞⻛控或者 QA 的职位，这些是 cost center，都是公司希望压缩成本的职位，前途不⼤。没有哪个⽼板会排斥能够给公司创收的⼈。但经济不好时，⽼板⾸先想要裁剪的就是后台 cost center 的员⼯。

3/ 优先考虑整个市场增⻓速度快，在市场[[涌现]]出来的领先甚⾄有[[垄断，稀缺和财富的关系|垄断]]优势的公司。这实际上排除了绝⼤多数早期的没有营收的，没有被市场证明的小公司。抬杠者当然总是可以举某个成功的小公司的反例，但这并没有统计上的意义。

4/ 职场遇到发展瓶颈时，不要头痛医头，脚痛医脚。要从⼀个更⾼的⻆度，寻找问题的本质和根源，然后去解决问题。⻓痛永远不如短痛，不解决本质问题，它迟早还是会回来找你⿇烦。

5/ 要花时间打造个⼈品牌，让更多⼈知道你的存在，知道你的才能，而不是偏安在某个公司的岗位上⻓期默默⽆闻。在社交媒体上⻓期发表有⼲货的⽂字，是⼀个有效⼿段。你会发现潜在市场⽐你的想像要⼤的多，市场的真实需求也和你的臆想有很多不同。潜在客户不断从你想不到的地⽅来找你，和你四处发简历找⼯作，是两个完全不同的体验。

6/ 当你接触真实的世界和市场时，会发现有些赚钱的机会和主流媒体上宣传的完全不⼀样。有些被⼈忽视误解的领域有赚⼤钱的机会，但是周围⼈⼀直不理解。有些被主流认为有⾯⼦有钱赚的职位实际很苦逼。你会困惑很⻓时间。但最终要相信⾃⼰⻓期实地的体验，而不要被媒体的虚假宣传或者错误认知误导而丧失主⻅。

7/ 从⽼板的⻆度而不是技术⼈员的局部⻆度思考理解问题，很多困惑就⼀下⼦清楚了。把⽼板当成⼀个⽣意上的合作伙伴，要尊重，要合作，要思考如何为他增加价值，但不必事事唯唯诺诺。⽼板如果不能为你的贡献回馈相应的价值，就必须寻找更好的合作伙伴。

8/ 要⽴⾜于⾃⼰的特⻓，寻找建⽴属于⾃⼰的与众不同的局部优势，然后越滚越⼤。⼤部分你看到的别⼈成功的案例你⽆法复制，原因之⼀是你并不具备他们⼀开始就有的局部优势。

9/ 没有正确的选择，只有（涌现出来的）最不坏的选择。在知识⾯，接触⾯还很狭窄的情况下讨论对错得失没有太⼤意义。⻅得多了，好的选择⾃然涌现。把时间精⼒投⼊到学习各种优秀知识，接触各种优秀的⼈上⾯，好的结果⾃然涌现。

10/ 没有捷径，需要⻓期不懈的努⼒构建⾃⼰的体系，just do it。

# 提防走捷径

⻓期看，上帝实际上是⾮常公平的。

有些⼈习惯做内幕交易赚快钱，这种[[回报递增，路径依赖|路径依赖]]，导致其判断⼒在别的地⽅形同⽩痴。⼀旦丧失权⼒寻租带来的信息优势，⻢上成为技穷之黔驴。

有些⼈习惯剽窃他⼈成果和知识产权，但这种路径依赖，导致其⾃⾝的原创能⼒被⾃⼰扼杀，而且对其抄袭对象形成严重依赖。

很多不付代价，想走捷径的内⼼冲动，和吸毒⽆异。要远离那些只想走捷径的⼈，否则迟早会被他们拉下⽔。

# 看起来很忙，和是否有效是两码事

看起来很忙，和是否有效是两码事。

从节能和提⾼效率的⻆度看，最有效的操作是不断计算未来将朝哪个⽅向移动，然后尽量以最低的代价去提前布局和等待。

而考虑的时间维度越⻓，可能撬动的不对称的巨⼤回报的机会也更多。

因为短期⼤家都可以看到的明显的东西，竞争太激烈，代价太⼤了。而且时常代价⼤到回报是负的。

对短期的算计，最⼤的⼀个问题是低估竞争者的存在。竞争者的出现常会让你的劳动价值接近于零。对于⻓期的算计，则有⼤概率会发现⼀些精彩的⽆⼈区。

# 是否算实⼲看⻓期效果

很多⼈会有个错误的直觉：

认为只有花很⼤⼒⽓的⾏为，才是实⼲。

所以喜欢天天把砖头从⼀楼搬到⼗楼，再搬回⼀楼，这样很有成就感。

是否算实⼲，看⻓期效果。如果搬了⼏年砖，把⾝体搞坏了，赚的钱还不够付医药费，那肯定不算有效的实⼲。

认知有点像古⽣物[[演化|进化]]出来的视觉。有视觉的⽣物不⼀定有强健的肌⾁，但肯定可以轻松把没有视觉或者视觉低下 / 但肌⾁强健的⽣物给灭掉。认知框架准确的⼈看上去好像⽆所事事，但也可以轻松碾压认知图景完全错误的⼈群。

# 以 KPI 为导向的问题

意识到以 KPI 为导向来指导⾃⼰或者别⼈的⾏为，会存在⼀个问题：之所以追求 KPI，本质是因为发展中遇到某个瓶颈，增速受到限制。追求某个 KPI 的过程中，不免有意⽆意地⼲了「拆东墙补西墙」的事。即使真正实现了 KPI，会发现⾃⼰在别的地⽅蒙受了损失或者打了折扣，最后结果并⾮⾃⼰真正想要的。

当有瓶颈存在，短期内完成 KPI 成为⼀个不可能的任务时，⼈们的应对⽅法往往是：

1. 牺牲别的地⽅的隐性资源来满⾜显性的 KPI 指标。⽐如牺牲健康去赚钱。
