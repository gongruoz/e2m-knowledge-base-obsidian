# 脱离做题家状态

摘要: 做题家不断为了外部的 KPI 指标优化自己的能力，自驱的出题家能够为自己的选择和兴趣承担责任，长期跟随内驱的目标不转移，从而累积结构性优势，并基于其获得不可替代性和议价权。
章节: 论做题家和出题家｜脱离做题家｜超级软件平台的标准控制者｜给自己创造准入许可

# 论做题家和出题家

1/ 「做题家」是流⾏于⽹路的戏谑⽤语，最初指那些勤奋努⼒，擅⻓做题考⼊名校，但缺乏资源，⽹络和全⾯的视野，在现实中屡屡受挫，怀才不遇的⼈。笔者作为⼀个前优秀做题家（数学竞赛湖北省第⼀名），对其⼼态和缺点还是有发⾔权的，在此拆解分析⼀下，与⼤家共勉。

2/ 应试教育花了⼗多年把做题家打造出特定的⾝体习惯，包括并不限于：

- 寻求短平快的明确的答案；
- 对⻛险、模糊和不确定性容忍度低，并会因此坐⽴不安；
- 线性思维；
- 把难度等同于价值；
- 把创造价值等同于捕捉价值。我举个例⼦来理解「创造价值和捕捉价值的区别」。⽼板拿了 100 块的利润，拍拍你的肩膀说，「你⼲得好，我说话就硬！」（you did a great job!），然后年终分给你⼀毛钱的奖⾦，或者花⼀分钱制作⼀些奖状、奖杯、锦旗送给你，再给你⼀些诸如「本⽉最佳员⼯」的荣誉称号。
- 思维模式简单化僵化，喜欢把⾃⼰的强项当作榔头，以为世界上所有的问题都是钉⼦，使劲敲⼀下就可以解决；
- 拒绝承认⾃⼰的弱点，缺乏从零开始的勇⽓；
- 喜欢和周边实时攀⽐各种 KPI（考分、地位、⾦钱等等），如果某种公众认可的 KPI ⽐别⼈强就沾沾⾃喜，如果⽐别⼈差就咬⽛切⻮捶胸顿⾜；
- 缺乏独⽴构建⾃⼰的独特体系的勇⽓、⾃信和耐⼼。

这些⾝体习惯不可能⼏周、⼏个⽉甚⾄⼏年就完全摆脱。

3/ 做题家相当于别⼈把框架和 API 早已定义好了，他和⽆数竞争者⼀起⽐赛谁能更⾼效地完成底层和后台的实现。但选择这条道路后，也就意味着他始终处于⼀个标准化的、有⽆数潜在替代者的弱势地位。但你要说他弱势他还不服⽓，他会说，我做的事情需要很⾼的智⼒和学历呢，我能脱颖而出，我是强者。

4/ 优秀做题家可以看成⼀种浅层神经⽹络，在局部拟合得⾮常好（考分⾮常⾼），⼀旦出现新情况（到了社会上），拟合失效。本来可以增加新的⼀层神经元来更好地抽象客观事实（而且更轻松），他们却坚持要继续在同⼀个浅层抓狂地继续拟合。按照⼀位哲⼈的话说是，「喜欢改参数，不愿意换算法」。

5/ 按做题家培养的小孩，被家⻓逼着填鸭式的学习，很难理解⾃发凭兴趣⻓期迭代的妙处。只是⼀味追求短平快，最终会遇到增⻓瓶颈而出不来。捏软柿⼦才能真正迅速迭代。很多⼈的问题是想⼀蹴而就，啃硬⻣头半天啃不动，浪费⼤量时间而没有任何进步。同样时间可以到外⾯找五百个软柿⼦捏，捏完后发现原来那个硬⻣头早已不在话下了。

6/ 做题家习惯于「直接正⾯攻击」达到⽬标，但这种⽅式在复杂系统内实操时的最⼤问题是遇到的阻⼒会越来越⼤，竞争越来越激烈，容易陷⼊恶性循环，就是使劲越⼤反抗越⼤。如遇到⽆法克服的阻⼒出不来，就完蛋了。英国军事理论家李德哈特（1895-1970）推荐的「间接⽅式」（indirect approach），本质是始终避免耗费资源在阻⼒过⼤的地⽅，始终让⾃⼰保持有很多选择和良性循环的态势。

7/ 考分⾼的做题家，相对于有强⼤⾃发兴趣的探索者，⻓期看之所以更难有⼤成就，原因是：短期的功利性过强，对于⽆法迅速打分、⽆法通过⾼分证明其优越感、⽆法迅速产⽣价值的东西毫⽆兴趣，因此往往视野狭隘，在和未来的连接组合中缺乏准备。这是⼀个怪圈：视野狭隘，所以就更缺乏动⼒去探索和拓宽视野。

8/ 真正的艺术家和创作者，为兴趣和⾃由而创作，而不是去迎合讨好某个特定⽬标的受众。违背内⼼去迎合外界定义的 KPI，去讨好外⼈，是⽆法持久的，而且对⽅很容易可以感觉到，并因此对你的态度转为轻蔑。伟⼤的艺术家和创作者，永远是潮流的领先者，而拒绝做外⼈⽀配的做题家。

9/ 「解决当下某个具体问题」的创新，相对⽽⾔吃⼒而不够讨好，因为问题的框架本⾝已经固化了，已经有若⼲竞争者和（还不够好的）替代⽅案，所以限死了可能获得利益的上限。创造或参与⼀个全新的还不被理解的体系的构建，会随着体系本⾝的迅速增⻓发展，和各种新机会指数型的[[涌现]]，⼀起指数型增⻓。因为整个体系的⼤的框架在迅速膨胀，所以发展的空间⾮常⾃由，可能仅仅是因为⽐别⼈多走⼏步，尽管姿势歪歪扭扭踉踉跄跄，仍然可能获得极为丰厚的回报。

10/ 前者是「做题家」，后者是「出题家」。

11/ ⼗⼏年前，当⼀些⻛险资本家傲慢的诘问「脸书能够解决什么问题？」时，他们恰恰错过了投资⼀个伟⼤「出题家」的机会。

12/ 不能积累、叠加、创造[[复利]]的事情，都不值得去做。⼀个事情遇到回报递减的增⻓瓶颈了，就不再值得去做。必须换个⽅向，寻求新的突破。虚张声势的花架⼦，⾃⼰清楚并没有实质性进步的东西，不值得去做。执意要去做不值得做的事情，就是⾃欺欺⼈。单维度猛推的成功的做题家们，在被出题家早已定义好的框架内，迟早会遇到其增⻓瓶颈，然后会在抓狂地绕过瓶颈的努⼒中，不断掉⼊各种坑⾥。当然，早掉坑⽐晚掉要好多了。

13/ 优秀做题家⼀般对「出题家」会有本能的厌恶，⼀是因为少数冒头的看似智商不⾼的「出题家」，会以看似极小的代价获得巨⼤的利益；⼆是为⾃⼰⻓期积累的做题技能在新的体系⾥⼀点都⽤不上而感到极为愤怒。

14/ 「做题家」的特点是模式成熟，短期⻛险有限，但⻓期回报有天花板甚⾄会变负。「出题家」的特点是起步期间破产或饿死的⻛险⼤，但如果能突破某个[[阈值|临界点]]，⻓期回报指数增⻓⽆上限。从做题到出题的跨越，需要不断低成本[[试错与纠错|试错]]，增加⾃⼰的⽹络和体系复杂度，寻找可以产⽣[[自催化，正反馈循环|正反馈循环]]的切⼊点。

15/ 优秀做题家，很难摆脱⾃⼰的锚定偏⻅（anchor bias），在遇到微妙的悖论时喜欢痛快地喷和抬杠，而绝对不愿深度思考。锚定偏⻅，就是认为⾃⼰过去⽣活经历中遇到的各种事物的参数值是天经地义、正常的。如果发现参数值超越⾃⼰的经验范围，就⼀口咬定是反常的、错误的，而没有去深挖背后的场景是否早已发⽣微妙的改变。再往深挖，⼤家都喜欢只看表⾯数字，而不愿花⼒⽓研究底层的复杂机制。把墙上的时钟指向，等同于真正的时间；把相关性等同于因果性；把「观察性研究」（observational study）等同于「随机控制实验」（randomized control trial）。

16/ 做题家更本质的问题是没有独⽴⾯对⻛险和评估⻛险的能⼒。因为他成⻓过程中都是在⼀个温室⾥，做不了题损失不⼤，能做题就可以赚更多。遇到超过其做题能⼒的全新情况时，做题家很容易惊慌失措，而缺乏直⾯⻛险坦然⾏动的勇⽓。做题家可能鄙视出题家智商不⾼，但就愿意独⽴承受⻛险这⼀点，做题家最后还是得⽼⽼实实给出题家打⼯。短期看做题家占点小便宜，⻓期看[[活下来就好，及时出场就好|活下来]]的出题家占⼤便宜。

17/ 做题家在羡慕少数出题家获得巨⼤利益，并试图转变成出题家的过程中，会有两种不同体验：⼀是在顺⻛顺⽔的⼤⽜市时⼊场，然后感叹，原来钱这么好赚，早点当出题家就好了。⼆是⼊场后遇到熊市，损兵折将丢盔卸甲，然后感叹，我太贪⼼了，愿以后世世代代不做出题家。然而世间终究没有好办法让你便宜占尽⻛险全⽆。

18/ 做题家有个挥之不去的幻觉，就是拼命把题做好了，⾃⼰就可以进⼊核⼼利益阶层。殊不知，出题家冒了很多⻛险，经过⻓期积累才获得现在的地位，怎么可能随随便便释放主要利益给没有承受过⻛险的做题家？再说，有那么多做题家来竞争某个预先定义好的岗位，⾃然也就限制了他们议价的能⼒。

19/ 做题家在⼀起，会因为彼此攀⽐做题能⼒的本能，而陷⼊更加努⼒做题的沼泽，⽆法⾃拔。改变做题家的本能，需要能够接触到更多有价值信息，看到更多新的⽆限游戏。但新的有价值信息，不可能⾃⼰坐着就有⼈喂到你的嘴边。而获得有价值信息，⼜需要兴趣产⽣的源动⼒，推动⾃⼰可以持续不断摸索。所以确实⽆法和⻅识短的做题家有效沟通，还是直接拉⿊清净。

20/ 成为「出题家」的前提，是需要⼀个⾃⼰拥有事实上的 API 定义权的体系，有⾜够多玩家愿意参与你的⽣态，服务你的 API 来分⼀杯羹。出题家的地位往往来⾃于对某些稀缺资源和关键节点的控制，很多时候这些控制⼒不是刻意计划，而是做着做着就突然发现⾃⼰有这种⼒量。但这和具体专业做题能⼒，往往⼀点关系都没有。

做题家和出题家的区别是，前者是短期利益驱动，后者是兴趣和信念驱动。

做题家常会追逐⼀些表⾯的泡沫，甚⾄⾃⼰知道是泡沫，也要⾃欺欺⼈去追逐，只因为看上去利益⾮常诱⼈。

出题家即使没有短期利益驱动，也会为⾃⼰的兴趣或信念而废寝忘⻝的奋⽃，因为在做事本⾝⾮常有趣，做事过程中⾃⼰的能⼒和⻅识得到真正的提⾼而绝⾮虚幻的泡沫，⻓远看⾮常有价值有意义。

有的时候做题家和出题家看上去是在做同样⼀件事，但熊市来临时，他们就会分道扬镳。做题家会做⻦兽散，出题家继续乐此不疲地迭代。

在表⾯上没有短期利益的地⽅，出题家会发现竞争出奇的少。做题家满⼼欢喜地追求某个短期利益点，但越努⼒发现越拥挤，竞争越来越激烈，成本越来越⾼，因为⾃⼰缺乏关键节点和资源的⽀配权，屡屡被玻璃天花板弹回来，原来的如意算盘成为南柯⼀梦。

要成为出题家，最好在有巨⼤潜⼒并快速增⻓的⾏业⾥寻找引起你的兴趣的切⼊点。快速增⻓期，会有很多真空需要填补，这时竞争不⼤甚⾄根本没有，只要你能挺⾝而出，即使智商不⾼，也已经赢了。为什么必须有巨⼤潜⼒？因为这意味着⻓⻓的增⻓曲线，即使错过这个机会，很快下⾯有新的机会等待你去填补。

出题家不怕⼲脏活累活。这并不意味着他们喜欢脏活累活，而不喜欢利益。实际情况是，因为兴趣驱动使他们不怕⼲脏活累活，⼲着⼲着，突然发现这⾥涌现出远超想象的巨⼤利益。

做题家们因为都不想⼲脏活累活，都想追求看得⻅的短期利益，他们的道路反而越来越拥挤。⼀旦他们追求的利益点成为⻝之⽆味的鸡肋，才发现⾃⼰过去的积累⽆法复⽤，光阴完全虚度。

做题家的本能是，看到别人做出好的东西，不管自己的能力如何，马上就想模仿，竞争和占有。但这也给自己很大的精神和时间压力，每天忙于各种追逐和救急，如果（大概率）竞争不过就是竹篮打水一场空，白白消耗自身资源，实际上在退步。

出题家的本能是，看到好的东西，就想如何利用它构建新的更好的东西，没有时间压力，熬得越久潜在可能性更多。这种潜在可能性，主要来自外界复杂度的持续增加，和自己与外界精准连接能力的增强，而不是像做题家那样，每天咬牙切齿，捶胸顿足，赌咒发誓，试图从石头里面挤出水来。

如果你把自己和世界的互动方式，尽量设计成一种合作共赢的态势，那么日常的损耗就会默认一直很低，只要下足够的功夫，给足够的时间，自然可以定期捕捉到意想不到的硕果。

# 脱离做题家

「应试教育花了⼗多年把你打造成做题家，你别妄想⽤⼏个⽉甚⾄⼏周就摆脱。」（翻译⼀下：速成的企图是不切实际的。）

根据我的经验，跟随⾃⼰的兴趣来写作，是深度思考和提⾼⾃⾝能⼒的真正捷径。即使把别⼈的话抄⼀遍，抄写的过程中也常常⾃然涌现出新的感悟。

「刚刚脱离 996 怪圈的时候，你先不要太看重钱。先搞定能⼒（有了能⼒，钱⾃然不是问题）。而为了搞定能⼒，你需要时间……利⽤你的议价能⼒，在获得同等报酬的情况下，降低⼯作强度（这样时间⾃然多了。而保持同等⼯作强度去挣更多钱，反而不是最佳策略）。」

「好奇⼼这个特质具有普遍性，⼜具有脆弱性……普遍性指的是：⼤部分学龄前⼉童天⽣就有这个特质。脆弱性是指：这个特质很容易被摧毁，且很难被重建。」

「如果某个活动是你真正的兴趣，那你不会满⾜于『只停留在该领域的⼼理舒适区』……通过不断突破⾃⼰的⼼理舒适区，你在这个领域的能⼒得到提升，同时你的⼼理舒适区的范围也扩⼤了……突破⼼理舒适区有的时候是很困难的，但是在突破的过程中，过程性的快感会伴随着你，⼀旦实现突破，你会获得结果性的快感。」

「什么是真正的兴趣爱好？三分钟热度，不是真正的兴趣；动机带有功利因素，不是真正的兴趣；来⾃外在的动机，不是真正的兴趣；纯感官刺激本能驱使的⾏为，也不是；被动的⾏为（⽐如边⼯作边听⾳乐），也不是；始终停留在⼼理舒适区，也不是。」

「兴趣和爱好导致的快感，⼤致分两类：过程性的快感，和结果性的快感。结果性的快感，只在短暂时间段发⽣，但强度很⾼。过程性的快感持久但强度不⾼，但也很重要——这类快感使得你可以持久从事感兴趣的活动，即便在你尚未获得成果的阶段，它也在起作⽤。」

# 超级软件平台的标准控制者

1/ 软件定义⻋，软件定义钱，软件定义⼈，软件定义和吞噬世界。

2/ 所谓「软件定义」，最本质的优点之⼀，是因为硬件已经被软件抽象化了，底层的硬件可以随时更换成性能更好的模块，而不会因为硬件的更新而被迫要重写软件。

3/ 优点之⼆，是底层硬件充分抽象化，价格压到⾜够低之后，可以彼此互联，开发出以前完全不存在的软件应⽤。最⼤的利润，属于市场竞争中⾃发涌现出来的超级软件平台的标准控制者。

4/ 最悲催的是废了⽜劲把硬件做好，挣了点小钱，而放弃了对于软件平台控制权的争夺，然后给别⼈做了嫁⾐。

从某个⻆度看，接受专业化的⾼等教育，虽然有各种⾼学历和⾼⼤上的头衔，但最后的下场就是成为「软件定义社会」⾥⼀个被抽象化的，很容易被替代的模块。所以忙了⼀辈⼦，没有独特之处，缺乏强势的⾃我[[定价权]]。

一旦被卡在某个细分领域，就容易被标准化，被商品化，丧失定价权，沦落到食物链的底部。这就是做题家的宿命。

# 给自己创造准入许可

和很多人竞争某个演员的角色，很困难，千里挑一，总是被拒绝，很不爽。但如果你写出好的独特的剧本，让剧本里的角色为自己量身定做，那就没有人和你竞争。这就是 Matt Daemon 试图打入好莱坞圈子，总是失败，后来依靠写 Good Will Hunting 剧本而获得奥斯卡奖的经历。

研制火箭，去和别人竞争有限的卫星发射市场，障碍很多，业务有限，很痛苦，不爽。但如果你直接开辟卫星通讯业务，自己成了自己最大的客户，形成良性循环，那么在卫星通讯和火箭发射上，最终都没有人和你竞争。这就是 starlink 和 SpaceX 发展的启示。

不断研究市场运作的底层机制，不断逼近价值链的源头，这样就不会被一些中间人阻拦，避免「浪费大半生而不得其门而入」的悲剧。
