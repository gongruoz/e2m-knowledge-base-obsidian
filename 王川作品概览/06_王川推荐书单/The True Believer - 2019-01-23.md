# The True Believer

Date: January 23, 2019
作者: Eric Hoffer
原帖推荐语: Eric Hoffer 似乎是对群体行为特征总结最深刻的哲学家。他 1951 年写的 The True Believer，在很多细节上仍然非常逼真，并对其它领域有较大借鉴价值。码头工人的生活经历，比哈佛教授的理论管用多了 :)

把个体的行为特征，推广到个体组成的群体的行为特征；或者根据群体的特征，来评判个体的优劣，是大家都会犯的错误。群体特征主要取决于个体之间的合作连接方式。就像碳原子可以组成不同的同素异形体：石墨，金刚石，石墨烯， buckyball, 等等。 

Eric Hoffer 评论 Norm Chomsky :

"在（德国）哈斯堡帝国的最后岁月，一次大战之前，有一群非常聪明的人，犹太人和非犹太人都有，他们对即将到来的末日满怀期待。他们知道世界末日即将到来。我无法理解为什么这些聪明人，吃着维也纳的美食，睡着维也纳的美女，会从对即将到来的灾难的思考中获得巨大快乐。 答案是一样的。他们毫不怀疑自己将是统治世界的赢家，他们一心要清扫地板，重新开始。他们会给大家看世界该如何被管理".
