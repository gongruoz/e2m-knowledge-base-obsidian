# Necessary Endings && Never Go Back

Date: July 13, 2023
作者: Henry Cloud
原帖推荐语: Henry Cloud 这几本书都不错，值得细品。里面有些和宗教相关的内容，如果没兴趣，可直接跳过，不影响对核心内容的理解。要把做减法，断舍离，变得和 sp500 指数基金定期再平衡一样：自然，客观和果断。那么有机的成长也就自然会[[涌现]]。定期做减法实际上是一种全局化的，深层次的更高明的[[试错与纠错|纠错]]模式：你定期把低效率的思维和行为模式果断淘汰，自然就会吸纳更高效率的思维和行为模式。否则你常常会对某个局部的决策利弊，而患得患失，纠结半天，耗费脑力，也错过了更大的高几个数量级的利益。美国早期的巨富 John Jacob ( 1763-1848) 在 1799年之后就不断在曼哈顿买地屯地，但他自己恐怕也没意识到死后，电梯技术的改进对于纽约地产价值的推动。
