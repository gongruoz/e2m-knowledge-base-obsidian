# The True Believer

Date: April 19, 2019
作者: Eric Hoffer
原帖推荐语: Eric Hoffer 老师说： 「自卑感会让人产生最为非正义的和罪恶的狂热；因为自卑者对于揭露自身错误和责任的真相，有不共戴天之仇」。 （The True Believer, 第 94 页） 这可以解释资本市场一些看似荒谬却又顽固的现象。不要去做空狂热，只能坐等其自我毁灭 :)
