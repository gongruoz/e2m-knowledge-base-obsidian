# Sizing up consciousness

Date: January 30, 2019
作者: Marcello Massimini 和 Gulio Tonon
原帖推荐语: 读 Marcello Massimini 和 Gulio Tononi 的 「 Sizing up consciousness 」 有感： 现在的人工智能技术，只是在确定了游戏规则后，可以更加高效地完成设计者所指定的任务。但是它和「自我意识」是两个完全不同维度的东西。可以高效下棋的 alphago, 从「自我意识」理论的研究者来看，仍然是个僵尸 「zombie」，它还没有形成更复杂的不可分割的信息整合，也不具有独立的感受。  纯粹粗暴地模拟大脑几百亿神经元的计算，可能只是创造了一个更复杂的僵尸，形似而非神似，并不是一个真正的有「独立自我意识」的东西。

我的理解： 「僵尸」可以看成是某个生命体在特定时间截面上的表象，但是它的根本问题在于缺乏一种主动的超级「可塑性」， 就是如果环境改变了，输入输出完全改变了，「僵尸」系统完全没有能力去改变自身以适应环境，还在老调重弹。
