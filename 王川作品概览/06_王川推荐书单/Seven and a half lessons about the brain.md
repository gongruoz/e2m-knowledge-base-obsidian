# Seven and a half lessons about the brain

Date: January 3, 2021
作者: Lisa Feldman Barrett
原帖推荐语: "从新陈代谢角度看，要让大脑学会与难以预测的东西打交道，非常耗能。
所以不出意料，人们制造了所谓的回音壁，周围听到的新闻和观点都是强化自己已经相信的东西，这降低了新陈代谢的消耗，避免了学习新东西的不适。
不幸的是，这也降低了人们学习可能改变自己观点的东西的概率。"
