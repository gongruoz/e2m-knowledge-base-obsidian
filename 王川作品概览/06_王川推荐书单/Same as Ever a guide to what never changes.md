# Same as Ever: a guide to what never changes

Date: November 15, 2023
作者: Morgan Housel
原帖推荐语: 「简单是真理的一个标志，... 但复杂往往有一种病态的吸引力。如果你在学术界给别人上课，从 alpha 到 omega 讲得非常简单清晰，听众会觉得被骗了。酸楚的真相是，复杂比简单更好卖。」
因为复杂意味着花费了功夫，深思熟虑。如果你能讲出一些别人不懂的道道，就会在外人心中制造一种神秘感。复杂给人一种舒适的掌控感，而简单很难和无知区分开来。

# 《永恒不变：关于亘古不变之事的指南》认知解放分析

## 洞见库

### 基石观点

**1. 人性恒定论**
霍华德·马克斯认为人类行为模式在历史长河中保持惊人的一致性。尽管科技、社会结构不断变革，人类的基本心理驱动力、认知偏见和决策模式却几乎未变。这一观点构成了他"关注不变之事"投资哲学的基础。

**2. 周期性而非线性的历史观**
作者拒绝进步主义叙事，提出历史是周期性的，而非线性进步的。市场、经济和社会现象往往遵循可预测的模式重复出现，因为它们由人类不变的心理特质驱动。

**3. 极端事件常态化**
所谓的"黑天鹅"事件实际上是历史的常态。人类倾向于低估极端事件的频率，高估我们预测和控制未来的能力。

**4. 情绪驱动的市场**
市场不是由理性计算驱动，而是由情绪、叙事和群体心理主导。投资者应关注人类情绪的永恒模式，而非仅仅分析数据和指标。

### 边缘洞见

**1. 适应性悖论**
马克斯暗示了一个深刻悖论：人类最强大的适应能力恰恰阻碍了我们认识不变规律。我们过度关注变化和创新，反而忽视了更根本的恒定模式，这种"适应性偏见"本身就是一种不变的人类特质。

**2. 知识的反向价值层级**
书中隐含一个颠覆性观点：在投资领域，最有价值的不是最新、最专业、最复杂的知识，而是最古老、最基本、最简单的人性洞察。这挑战了现代知识经济中"新颖=有价值"的主流假设。

**3. 叙事作为认知陷阱**
马克斯暗示人类创造叙事的能力既是我们最强大的认知工具，也是最危险的陷阱。我们无法不通过叙事理解世界，但叙事本身往往掩盖了更基本的循环模式。

## 认知自由指南

### 隐含前提揭示

1. **进步的幻觉**：马克斯的框架隐含假设现代人并不比古人更理性或更明智，只是拥有更多工具。这挑战了现代社会的进步叙事。
2. **决定论倾向**：作者框架暗示人类行为在宏观层面高度可预测，这可能低估了真正创新和自由意志的作用。
3. **反专家立场**：文本暗含对专业知识和专家预测的怀疑，认为简单的历史模式识别可能比复杂模型更有价值。

### 洞见催化问题

1. **如果人性确实不变，为何不同文化和时代的行为模式差异如此之大？**
2. **是否存在真正的"范式转换"时刻，使某些历史模式彻底中断？还是所有表面上的革命最终都回归某种基本模式？**
3. **如果我们能完全理解并接受人类行为的周期性，这种理解本身会不会改变这些周期？**
4. **马克斯的"关注不变之事"框架是否本身就是一种时代产物——特定于经历了多次市场周期的投资者？**

### 平行思维框架

1. **复杂适应系统视角**：与马克斯的周期性模型并列，可以考虑市场作为复杂适应系统，既有稳定模式又有[[涌现]]特性，允许真正的新颖性和不可预测性。
2. **文化[[演化|进化论]]框架**：虽然个体心理可能相对恒定，但集体知识和机构可能累积进步，创造真正不同的环境和结果。
3. **多尺度分析模型**：在不同时间尺度上，可能同时存在周期性（短期）、线性进步（中期）和范式转换（长期）。

## 阅读策略

根据价值密度分布，建议重点关注:

1. 第一章和结论部分，这里包含马克斯对人性不变特质的核心洞察。
2. 关于市场周期的章节包含最具操作性的见解，特别是关于恐惧与贪婪循环的描述。
3. 可以略过具体市场案例的细节，因为它们主要作为论证工具，核心洞见在更抽象的模式识别中。

## 惊喜视角

马克斯的"关注不变之事"哲学与古代斯多葛派哲学存在惊人相似之处。两者都强调：

1. 区分可控与不可控因素的重要性
2. 对人性弱点的清醒认识
3. 情绪控制作为成功的关键
4. 周期性而非线性的世界观

这暗示投资智慧可能更接近古代哲学智慧，而非现代金融理论。马克斯本质上可能是一位穿着投资者外衣的斯多葛派哲学家，他的投资框架实际上是一种生活哲学。
