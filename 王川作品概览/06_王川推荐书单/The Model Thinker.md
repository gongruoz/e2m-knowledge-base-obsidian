# The Model Thinker

Date: February 3, 2019
作者: Scott Page
原帖推荐语: Scott Page 的新书 The Model Thinker 也不错，深入浅出，对于了解复杂系统理论非常有用。三个月之前刚出版的。大部分人只能理解「爱拼才会赢」的简单机械的模型，或只有对自己生活经验的直觉感受；那本书比较系统地介绍了诸如 system dynamic model, threshold model w/ feedback, diffusion/contagion model, signalling model 等二十多种更复杂的情况
