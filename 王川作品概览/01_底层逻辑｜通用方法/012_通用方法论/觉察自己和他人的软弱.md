# 避免软弱

永远不要把自己的命运寄托于他人的善意，永远要走那条给自己增加更多选择的出路（即使短期有各种困难和挑战）。

人的软弱本质是缺乏选择权。选择权的缺失是个不断积累的过程，在每一个岔路口如果本能的随波逐流，默认那条短期看似容易轻松的道路，默认让选择权悄悄从身边流失，越来越少，最后默认走上任人宰割的道路。扩大选择权需要不断检讨自己的觉知（awareness），不断纠正自己随波逐流的微小的坏习惯。

避免软弱的第一点是，发现错误之后，马上[[试错与纠错|纠错]]。不能做鸵鸟，不能因为羞耻感或而拒绝直面错误，不能因为沉没成本和纠错初期的巨大痛苦而拒绝行动。纠错的操作做了几次后，也会形成肌肉记忆，也就不那么痛苦了，甚至有时因为纠错之后获得巨大的收益，慢慢潜意识里把纠错变成一种非常期待的事情。

避免软弱的第二点，是保持较大的克制，始终在各个维度给自己留下较大的冗余。远离那些孤注一掷，成天嚷嚷要 all in 的赌徒。但可以注意等赌徒穷途末路，不得不砸锅卖铁时，廉价接收一些他们的资源。

避免软弱的第三点，就是保持开放的心态和信息管道，不断通过「打破禁忌」和「刻意探索」，把自己的实力提高到一个新的层次。这是一个永无止境的路途。

「我们背叛往往是因为软弱，而不是刻意要去背叛。」——所以要远离软弱者。

远离软弱者。因为他们迟早会因为软弱而背叛。

「打破禁忌」，和「刻意探索」，是把自己水平提高到一个新的层次的必经之路。比如很久以前我被灌输一定要一日三餐，一定要准时吃饭的理念，否则对身体不好。潜意识里视其为不可逾越的红线。实际上这个禁忌完全可以打破，有时一日两餐（不吃晚餐）毫无问题。吃早饭的时间也可以灵活调整，如果前一天晚上吃多了，早餐时间向后推两三个小时也没问题。这样可以轻松而精准的维持体重在稳定健康的水平。

一日三餐是工业化时代之后人类社会形成的习惯，在此之前人们经常挨饿，因此身体构造实际上对这种时常挨饿的状态可以较好的适应，吃多了后反而造成各种代谢和健康问题。很多时候我们遇到的棘手问题，本质在于不敢打破禁忌，不去质疑某些观念背后的隐含假设。真正打破禁忌了，窗户纸捅破了，发现没有什么大不了的，那么沿着这个方向继续摸索，可能会以极低的成本获得极高的回报。

再比如我们以前被灌输的运动习惯，是每天同一时间，做同样的运动，运动量和强度越大越好。实际操作上，这种无脑的简单粗暴的做法会长期对局部肌肉组织施加过大的压力，不给它充分时间休息恢复，运动成绩也就上不去，而且容易受伤，事倍功半。而根据一些资深教练的经验，刻意的安排休息日和多样化的运动，让身体每个部位都有足够时间休息恢复，大部分时间在低强度的有氧训练（心跳在最高值的 50-60% 之间），低于 20% 的运动时间在高强度的训练上，循序渐进的加量，训练成绩往往会更好，而且更轻松。

「刻意探索」本质就是承认探索的复杂性，承认要根据实际情况不断做进和退的调整。一味高歌猛进，或者一味龟缩退却，本质是一种不能理性直面现实的低智能的表现。

# 真正的强硬

真正的强硬，不是说很凶和别人去吵架，或者赤膊上阵去干仗。那是一种表象上的强硬的幻觉。

真正的强硬，是能够冷静的保持和扩大自己的优势地位，对于各种可能瓦解自身优势地位的短期诱惑，挑衅和陷阱，强硬的不为所动。 而别的不甘寂寞的意志薄弱者纷纷踩坑后，自然变得软弱，不攻自破。

# 亲疏有别

人一定要亲疏有别，否则必然被潜在充满敌意的环境所反噬。

小白们被道德和情怀的说辞所忽悠或绑架，拿自己的核心资源（要么是父母的血汗钱所以不在乎，要么是自己的血汗和青春以为可以取之不尽）以极便宜的汇率置换外围的资源，很久之后意识到上了大当，已经太晚了。

# 虚伪之恶

伪君子比真小人更让人感到不安。因为伪君子当面说一套，背后捅刀子，意味着以后完全不可信任，下次打交道时大脑必须耗费更多资源，来提防他的各种欺诈。

伪君子自以为某个局部的博弈暂时占了上风，但下次别人就不和你玩了，一有机会就把你踢开。 而「君子」和「小人」的判断还有主观性，只要保持「真」，下次还有合作的余地。

# 观察嫉妒找到稀缺资源

有一个事情永远不会改变，就是人性的嫉妒，这是推进社会发展的一个动力，当然大家嘴上多不愿承认，否则让自己太没面子。人们更倾向于嫉妒同一个圈子的人，离自己比较近的人。与其让嫉妒对自己产生不必要的消耗，要注意观察别人的嫉妒导致的行为，会让人们未来争夺哪些稀缺资源。然后提前布局，享受别人因主观嫉妒而客观上给你支付的红利。

# 是否默认信任

分析事物有个很重要的角度，就是「默认是真」（default to truth），还是「默认是假」。如果某个人或者公司在某个地方撒了谎，那么下次不管他说什么，都应当默认为假，除非他有足够多的海量证据，证明其真实性。

在和外界交往过程中，不重要的事情，可以「默认为真」，这样减少自己搜索核实数据的工作量。但在投资这个事情上，随着金额和风险的增加，应当转为「默认为假」的极为谨慎的态度。

很多人决策上不断犯错误的一个根本原因，就是因为没有把「默认的位置」放在正确的地方。结果要么就是对外过于信任，过滤不够，让各类骗子乘虚而入；要么就是过于猜疑，给自己带来过高的不必要的成本。
