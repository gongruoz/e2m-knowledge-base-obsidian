# 根据反馈迅速迭代

经常遇到的一些提问，本质都是「我如何快速成功？快给我干货！」，这种提问的方式，表明其认知框架完全不对。

如果能够把自己置身于一个反馈快，[[试错与纠错|试错]]成本低的环境，答案自然浮现。否则在一个反馈慢，试错成本高的环境，再怎么挣扎都感觉有心无力。

成功的秘诀在于迅速得到反馈，迅速改错和迭代。反馈越快，迭代成本越低，迭代次数就越多，也就越容易成功。瞎搞半天，很长时间都没有市场的真实反馈，是通向破产的捷径。

# 把自己的活动主线设计成游戏

普通人容易沉迷电子游戏，因为反馈迅速，反馈强，规则清晰，可以在提升技能的过程中获得巨大成就感。高兴就可以接着打，不高兴就可以休息。

如果你理解了世界的更多真实运作机制，知道在哪里获得最强的反馈，知道反馈周期的大致长度，那就可以把整个世界当成一个巨大的电子游戏场。

绝大部分外人制作的娱乐活动 (电影，电视，各类演出，等等) 是一种分散消耗你的注意力的事情，应当严格限制在上面花费的时间。实际上如果你摸清更多世事的底层运作机制后，会自然把自己的活动的主线，打造出一种类似电子游戏的感觉，那么应当对于绝大部分娱乐活动就完全没有兴趣。

# 生活的游戏在于不断突破自己的约束

生活的游戏可以看成是日常遇到各种各样的约束（constraint），然后不断找出此刻最让自己有压迫感的约束，松弛它，突破它，或者从别的地方完全绕过这个约束。

每次依靠自己的努力，成功突破了某个约束的压迫，都有一种极为满足的成就感。但过了一段时间后枯燥感袭来，人会急切地想寻找下一个有关约束的问题，去解决它，突破它。

枯燥感会驱动你去解决新的问题。但如果不能正确地驾驭枯燥感，没有从约束的角度看问题，反而会画蛇添足，作茧自缚，人为制造了完全不必要的新的约束。

比如说，有的人本来没有太大经济压力，却要去折腾一些高风险的创业，结果原来衣食无忧的资金亏光了，身体搞坏了，给自己毫无必要地平添了健康和金钱的双重约束。

再比如，对于四十岁以上的中年人而言，身体健康的约束的重要性越来越大。主要有三个维度的约束：心血管健康退化，肌肉力量下降，和新陈代谢变缓（胰岛素敏感度下降）。如果不注意通过锻炼身体去刻意松弛和控制这三个约束，六十岁之后这三个约束加速收紧，恶性循环，让其它一切失去意义。

再比如，金融危机中那些高杠杆而被迫廉价抛售优质资产的投机者，可以看成是因为自身约束太紧，不得不以非常糟糕的价格和那些没有约束的买家做亏本交易。

再比如，维护权力的一个基本原则是，关键线程上自己总要保持两个或更多的选择，这样避免被单一选择所约束，否则被架空后会彻底丧失讨价还价的能力。

再比如，有些人旅游时爱寻求刺激，攀爬险峻的山路，或者去风大浪急的海滩玩冲浪，悄悄地增加了自己的约束而不在意，等到风险降临时已经来不及了。

约束较少的人，不一定意味着某个维度很强大，或者极为富有。但相比其它世俗意义上的表面的强者而言，他会大概率避免掉因为「约束过紧」而突然毁灭的风险。

「人在江湖，身不由己」「高处不胜寒」等俗语，只是对于「约束过紧」的一种无奈的表述而已。

与其和别人攀比某个单一维度的强弱，不如攀比谁的整体约束更少更松。

# 收集反馈，持续迭代

现在读⼀些书的动机，主要并不是为迅速获得特定的技巧，而是在寻找某个领域事物运作的真实底层机制，是否和别的我熟悉的领域的机制有相通之处。

⼀旦拨开迷雾，找到这种相通之处，会有⼀种强烈的愉悦感，⾃信⼼⼜上了⼀个台阶。如果还找不到这种相通之处，那可以说，我并没有完全理解其真实机制。

⽐如散打武术，和⼈际交往对话，有很多相似之处。散打⾼⼿，本质就是不要让⾃⼰露出破绽，并能很快识别利⽤对⼿的破绽。搭⼀下⼿，过两招，⼤概可以识别对⽅的⽔平在什么量级，打不过就赶快跑。但很多从未被训练过的⼈对于打架时⾃⼰暴露的各种低级破绽，完全没有任何觉知。

⼈际交往或做销售的⾼⼿，基本也是讲⼏句话，就⼤概可以理解对⽅的现状处境和动机，然后调整出有效的沟通⽅式。但很多没有接受过专⻔培训的⼈，甚⾄很⼤年龄了，仍然⻓期处于⾃说⾃话的阶段，和外界的沟通互动，处于⼀种惨不忍睹的低级⽔平。

真正提⾼⽔平，需要不断测试，收集反馈，频繁改进。⽐如散打的时候如果哪⾥挨了揍，很疼，就会印象深刻，迅速形成较好的姿态和本能来保护⾃⼰的薄弱之处。Jerry Seinfeld ⼆⼗多岁的时候，号称有曾经连续⼗⼋个⽉，天天到各个夜总会演出，给⾃⼰的表演录像，然后回放录像来改进表演技巧。

低⼿和⾼⼿的区别，在于后者的⻓期持续的改进迭代。而低⼿可能有各种低⽔平的陋习，形成习惯后很难改，甚⾄根本不知道，或者有点模糊的感觉，但没有条件和意志⼒去进⼊⼀个迅速迭代改正的良性循环。

从低⼿到⾼⼿的转变，⼀定不能⼀个⼈闷头傻练，否则⼤概率是在某个局部极值附近打转转。⼀定要走出去，到开放的世界去做各种测试，频繁获得各种反馈，学习各种新的技巧。那种传说中的很少和外界交流的「深⼭⽼林的武林⾼⼿」，基本可以肯定是瞎吹⽜，不符合常识。

所谓⾼⼿，基本上就是说在某个相关技能上，他的⼤脑记忆的存储量，是新⼿的很多倍。遇到各种困难和障碍，都能迅速拿出 N 套剧本来应对，因此看上去举重若轻。而新⼿往往遇到⼀个稍微复杂的情况，就不知所措，卡壳完蛋。

坏习惯纠正的⼀⼤困难是，很多坏习惯的本质原因是背后有另外⼀个或者⼏个弱点，导致坏习惯成为阻⼒最小的⾏为模式。⽐如⾝体某个部位肌⾁⼒量不够，导致某个动作⽆法做到位，然后攻击就没有⼒量，等等。有经验的⽼师傅⼀眼就可以看出来是什么问题，⾃⼰瞎摸索可能很⻓时间都⽆法跳出怪圈。

# 以终为始

稍微复杂一点的大项目，开始行动之前：必须先拷问自己真正要什么，然后不断推敲，反省，为什么要这个东西，背后真正的需求是什么，再一步步倒推，为了满足这个需求，真正该做什么。这种做事方法，一般来说，成本会更低，整体时间会耗费更少，过程可控。但实施这个方法，开始的时间花费要多一些。

而通常人的直觉是，一拍脑门说我就要某个东西，做的一步步过程中发现：要不断引入更多新环节，或者发现原来的目标无法精准满足自己真实的需求，需要加码。这样成本和耗时迅速爆炸式增加，越做越痛苦不堪，无法脱身，甚至把自己搞破产。这本书 「How big things get done"（大事是如何办成的）值得研读收藏。

比如说，某地官僚想要造一个连接某小岛和大陆之间的桥。一上来就开始讨论建桥的位置，长度，成本，时间等等细节。他们可能认为深入到细节的讨论很有成就感，但是，为什么要造这样一座桥？最终的目的是什么？这是最佳方案吗？为什么不能造隧道，增加轮渡，或者给岛上居民增加宽带互联网的接入方案？只有不断深入拷问真实底层需求，才是确保项目成功的基石。

# 避免自我合理化

人的决策机制天然有一种 "availability bias"，就是潜意识只愿意对喂到自己嘴边的，唾手可得的信息进行分析处理，这样必然自我合理化，说服自己接受一个平庸，甚至很糟糕的选择。

把自己的搜索空间扩大几十倍，甚至上百倍，可以根本上避免这种窘境。但要知道该如何甄别，有哪些关键指标和线索，什么时候用什么工具提高搜索效率，什么时候不能偷懒要仔细手工研究，这又是一门学问。但在这种战略高度的问题肯下功夫积累，战术上可以少吃十倍的苦头。

# 教练反馈之必要

百米冠军也要给自己找个教练。教练肯定跑得没有你快，但他的长处是可以观察到你有什么需要改进的地方，并且提出切实可行的建议。

---

如果你的教练让你自始至终觉得很开心，那就势必意味着他没有有效的纠正你的某些错误的习惯，尤其是那些根深蒂固的落后的有害的习惯。那你就无法真正进步。这对于体育锻炼，和其它很多领域都适用。真正的持续进步，就像做牙科手术一样，肯定有一段不爽的时期，即使打了麻药也觉得不舒服，强忍着不适做完手术，等麻药效果退去后，才能真正长舒一口气，原来的问题彻底根治了，我又更上一层楼。

# 建立秩序的本质

建立、输出秩序本质就是这样：

1. 保持开放。
2. 把坏的、假的东西严格过滤，剔除。
3. 把最好的、可以验证的真的东西不断引入。
4. 创造环境让好的东西，通过组合，自发演生出更好的东西。
5. 长期持续积累。
6. 有机制保证积累很难被破坏。

新手犯的错误是：

1. 闭门造车；
2. 亲疏真假不分，懒得去分，老被骗；
3. 不够挑剔，没有持续提高自己的[[机会成本]]，去引入最好的东西；
4. 主观性太强，没有等待好东西的[[涌现|自发涌现]]；
5. 缺乏耐心持续积累；
6. 没有搭建非对称的强大防护机制，抵御潜在敌人的攻击。

# 正反馈循环带来长期复利

[[自催化，正反馈循环|正反馈]]，和正反馈循环，有很大不同。

让原子弹爆炸的链式反应，是最经典的正反馈循环，过了[[阈值|临界点]]之后就可以躺平了。无法循环的正反馈，意味着你付出一次努力，收获一份正反馈，然后下次还需要继续从零开始，继续做功，才能继续收获正反馈。

短期的投机行为，一般很难产生正反馈循环，因为你能看到的投机套利机会，也会有人看到，竞争者越多，正反馈越弱，最后甚至变成大家全都亏钱全都玩完的死局。

好的投资，就是在抽象上观察到一个事物的某个维度正在突破临界点，产生链式反应，然后借力搭顺风车获得[[指数增长，S 曲线|指数增长]]。而且正是因为它是一个正反馈循环，你的参与本身，就会推动这个事情发展的加速。

# 好奇心

好奇心的本质，是「感觉再往前移动一点点，就会获得更多正反馈。」

缺乏好奇心，是因为习惯于一种「即使做了，也不会有什么有意思的正反馈」的心态，所以人就变得更懒惰封闭，所以就更难产生好奇心。

# 上瘾机制

垃圾食品的害处，关键的危害不在食品本身，而是其上瘾的特性。

食品精加工后会产生好吃的味觉记忆，不断产生想多吃的欲望，因此很容易过量，积累一段时间就会有各种涉及新陈代谢内分泌的慢性疾病。

同理，娱乐至死的各种垃圾信息，危害不在于信息本身，而在于其让人上瘾的特质，让接收者变成完全丧失判断力，任外界摆布操纵其情绪的行尸走肉。积累一段时间后，就不再有任何耐心去做稍微复杂一点的理性思考。

意识到对垃圾食品，或者信息垃圾的一种可能比较有效的免疫方法，是近距离观察它在后台是如何被制造出来的，和最底层让人上瘾的机制。

比如你和某个专门写爽文，策划拍爽剧的人近距离接触，听他详细解释这个东西的制作流程和细节，如何迎合观众读者上钩的技巧，那么你对它的观察体验角度就和普通消费者完全不一样，就更难落入上瘾的陷阱。

上瘾的一个必要元素是放任大脑对看不见的那部分东西去做脱离现实的想象，而如果能够从头到尾全部看得清楚，思维模型自然改变，不会有错误虚空的想象，觉得无非如此，也就自然不会上瘾。

---

让人上瘾的「稀缺回路」有三部分：

1. 潜在机会。
2. 无法预测的奖励。
3. 可以快速重复。

另外，人脑的一个缺陷是，把赌一块钱赢 80 分的游戏也视为一种奖励（虽然实际上亏了钱），这给老虎机的设计者以可乘之机。

# 深度工作带来心流的满足感

深度思考，如果用对了方向，产生了突破，把某个事情的从头到尾的底层机制彻底搞清楚了，会有一种深深的类似心流的巨大满足感。但问题是你不可能一开始就知道那个方向能够产生突破，所以只能够这里碰一碰，那里摸一摸，积累很多素材，突然有一天感觉快要把它们串起来了，就会特别激动。这本书 「Deep work" 部分原则我同意，但是对于 「quit social media" 的建议我不赞同。正确的利用 social media，可以帮你加速深度思考，发现新的连接和方向，避免在死胡同里纠缠浪费时间，好处是很多的。

对心流里面的「挣扎感」特别有深刻的体会，就是你在挣扎的过程中，不断有微小但是真实的进步，这种进步让你欲罢不能，非常执着和忘我，把事情弄通了以后有一种如释重负的非常舒适的感觉。

几十年前做数学题时会有这种感觉。现在思考一个感兴趣的问题然后再写出文章时也会有这种感觉。但是：

1. 必须自己命题，选择自己感兴趣的问题。给别人打工，完成别人布置的任务，很难获得这种感觉。
2. 不能有别人设置的截止日期。这个事情只能水到渠成，外界压力可能会有反效果。
3. 问题难度不能太低，也不能太高。要在努力挣扎而可以攻克的范畴内。

# 搭建实现目标的系统

与其设立目标，不如搭建实现目标的系统。

没有系统，必定在现实和目标相距较远的时候，忍受不住煎熬，病急乱投医。

急的后果一般是高价去买包装精美的假货，或者低价把自己的宝贝贱卖。

# 利用拖延，在正确的事之间切换

Piers Steel 在《拖延的方程》一书中写到，「决定你所追求的的东西的最大的因素，不是相关的奖励或者得到奖励的确定性，而是获得奖励的时机。你对于马上就可以获得的奖励的重视，远远大于那些需要等待的奖励。换句话说，你是冲动的。」

再换句话说，让自己更有行动力的方法，是能把自己的工作方式设计成经常可以获得微小的奖励。比如，能够让我坚持写作的一个关键，是每次发一些文字片段到社交媒体上，可以迅速收获读者的点赞和评论。

再比如，以前总觉得打太极拳有些枯燥，后来在等待微波炉热牛奶，或者烤面包时打太极拳，这样大脑潜意识里有一个新的奖励（面包烤好了，牛奶热好了），也就不觉得枯燥。反而等面包烤好的时候，还会觉得时间过得太快了，再多打一分钟才做收势。

Piers Steel：「我最有效的一招，是让我做的几个不同的事情互相竞争，为了拖延一个事情，而去做另外一件事。」

所以可以让自己不断在「读书，写作，锻炼，睡觉」这几个事情之间来回做竞争性的选择。

# 眩晕时关注远方

大脑如果收到来自不同的感知系统（视觉，内耳，本体感觉）的矛盾的信号时，比如晕车晕船时，会本能的产生一种眩晕和恶心的感觉。有一种理论说，这是一种自我保护机制，因为矛盾的信号可能意味着生病或者中毒，恶心导致的呕吐可以把体内潜在的毒素给排出来。

我以前上摔跤课时，连续做了几个前滚翻之后，大脑也会感到眩晕。老师提示说，眼睛订着肚脐眼看，会减轻这种症状。大概是因为肚脐眼的高度在滚翻时相对变化不大。

开车时，司机一般比乘客而言，更少发生晕车的现象。因为司机在控制车的走向，而且一般在看着远方的物体，所以他收到的感知信号是稳定的，这样各种微小的变化也符合大脑的预期，整个感知体系协调一致。而坐在后排的乘客，如果不朝外面和远方看，大脑无法预测车的运行的变化，就会被各种频繁的，自己无法预期，也无法控制的变化而搞得晕头转向。

这里实际上存在一个深刻的隐喻。就是当你感到迷茫和错乱的时候，本质是因为你的视野被挡住，看不清影响事物运作的底层真实机制，然后屡屡被和预期相差极大的挫折痛击。被痛击之后，不去努力发掘更底层的真实和原始的信息，而只是用自己「被」看到的一些表面的数据和现象，来重新调整预测（比如股市里的技术分析），然后又预测错误，折腾几回后，大脑「晕车」感强烈，然后唉声叹气，慢慢变成一个听天由命，随波逐流的人。

所以感觉错乱的时候：尽量迅速迁移到自己可以掌控的环境，尽量多关注预期比较稳定的远方。

所以资本市场一般对于可以给予稳定预期的事物，以较高的估值。在现实世界中，一方面必须要对给自己不稳定预期的人，保持高度警惕；一方面要给合作伙伴以稳定预期，这样才能降低长期合作成本。

# 改变环境和习惯即可改变自己

@erchenlu1：表现心理学家 Dr. Gio Valiante 最近在接受一个访谈时，谈到人怎样可以改变自己时，这段见解非常有深度：一个人一生中的产出和成就主要体现在我们反复习惯性的体现/表达上（expression of our repeated habits）。

人们常常在试图改变那些无法被改变的事物上浪费了太多时间。很多时候，一个人如果想改变自己的行为，其实只需要改变周围的环境就行了，根本无需耗费太多意志力。当你丢掉身份、自我、以及个人包袱时，填充这个空间的是关于[[创造力|创造性]]的自由。而这种创造的自由也代表着承担风险的自由。

王川：改变信息输入渠道是改变环境的很重要的一部分，也就很容易改变自己。这个观察也适用于他人。改变他人最简单的方法，就是改变其环境，所以有「孟母三迁」之典故。

这个 podcast 里面另外一段也是让我感慨万千：Dr. Valiente 提到，为什么有些人会非常有韧性（resilient）？因为他们对各种试错导致的失败习以为常，所以不会轻易放弃。而家长常常对孩子过于保护，怕他们失败，这样实际上是剥夺了他们在性格形成的过程中对失败体验的习以为常，也就阻挠了他们获得坚韧性格的机会。

# 不要过度优化

人在不同阶段和不同环境，需要优化（最大化）的指标是不一样的。有些指标，过了某个临界点后，它就不再成为限制你的自由度的瓶颈。继续努力突破提高，意义不大。如果不假思索地按照本能的习惯要去继续优化，反而会对自身造成不必要的损耗，有负面效果。

比如长跑成绩过了某个指标，就说明心肺功能足够好，足够健康了。如果硬要为了虚荣去和别人比拼成绩，大概率会对身体其它部位造成伤害，得不偿失。这时候更值得关心的可能是自己的其它某个健康指标，比如臂力，握力，核心肌群，等等。

与其说你要追求优化，不如说，本质上你要清除掉个人自由发展道路上的各种重大瓶颈。时间瓶颈，金钱瓶颈，其它各种隐性的你没有觉知到的瓶颈。

但如果为了去除某一个维度的瓶颈，结果给自己引入别的维度上的新的瓶颈，那就格外愚蠢和可悲。比如为了去除金钱的瓶颈，盲目参与自己毫无优势的创业，结果自己的时间瓶颈，健康瓶颈更加恶化，最后把自己逼到绝路上，金钱，时间和健康通通没有了。
