# 理解荒谬并从中获利

研究一个非常不合理的现象为什么能够长期存在，比研究批判这个现象为什么不合理，更重要更有趣。因为你一旦真正理解某个不合理现象为什么仍然长期存在，就可以举一反三，理解更多其它不合理现象为什么长期存在，然后就可能因势利导，发掘其中的巨大机会。

慢慢意识到，很多时候，你会看到一些人持有一些很明显和事实不符的，荒谬错误的观点的本质原因是：他周边有足够多的人持有这种观点，持有这种观点变成了一种时髦，一种美德信号（virtue signalling），一种让他合群并获取实际局部利益的生存之道。

这也意味着：

第一，你试图用事实真相的数据来改变他，是浪费时间，因为他的观点的改变主要依靠周边人的观点改变。这正如因为某个股票估值过高就开始做空，自己反而可能收获毁灭性的亏损。

第二，这种荒谬的现象，过去，现在和未来都不会改变，只不过表现的形式大不一样。

第三，真正发生改变的转机，在于他所在环境的人群的观点整体发生改变。这种转机往往来自于更高层面的，或者更遥远的地方的外力的冲击，这种冲击往往需要积累很长时间。转机很难提前预测，往往来自于你观察不到的地方。

第四，你必须理解和尊重这个现象的形成和转变机制，以让自己更好地适应环境，而不是像堂吉诃德大战风车一样，耗费大量精力和你想象中的「荒谬」去做无谓的斗争。

简单地指责某个现象「荒谬」，还属于比较低级的认知状态。

能够理解它为什么发生，它是否可以转变成「不荒谬」，需要什么样的外因才能促成这种转变，能够从这种现象中获利，才真正有价值。

而且一旦有过这种体验后，你的思维方式就再也不会回去了。你就发现这种现象和规律到处都是，所以每次遇到看似「荒谬」的现象你就开始激动起来，就有兴趣去发掘和理解底层的机制。

抱怨和谩骂「群体的不理性」，没有任何意义和价值。

「群体的不理性」是有其宏观规律和必然性的。尊重「群体的不理性」这个现实，不与其顶牛，顺应其趋势，在关键节点利用其规律来牟利，才真正有价值。

# 表象背后是利益交换机制

看到不公正不合理的现象，不能急着抱怨不公平，一要理解现象背后推手的金主是谁，二要理解金主背后是否有整个体系在源源不断给他输入资源。

如果不能对后面整个体系进行釜底抽薪，而是直接赤膊上阵和不公平现象斗争，最后往往会像堂吉柯德大战风车一样无效。

所有你看不懂的社会现象，本质都是因为你看不懂背后的金钱流动和利益交换机制。浪费大量精力和感情，去争论表面现象的「荒谬不合理」，而不深挖和研究背后的利益交换机制，实在是再愚蠢不过了。

搞明白后，第一，你不会再浪费时间做无用功。第二，你会更敏感的理解其它社会现象，并迟早找到顺势盈利的机会。

# **寻找规则失效的场景**

Munger 在视频中提到不建议大家用杠杆时，说了一个金句： Young man knows the rule, old man knows the exception.

这个总结可以应用到很多领域。换个角度，你知道某个领域通用的规则，相对价值有限；但你如果知道通用规则什么场景下不再适用，这里就有金矿。比如说，通常零售商不是好的投资，但亚马逊并不是纯粹的零售商，它还有高增长的云计算业务，是一个 exception；但当很多未经考验的南郭先生标榜自己是下一个亚马逊，要烧很多钱去增长的时候，你又要小心了。

# 无法自洽的地方出现新的知识

大语言模型本质是要在现有输入数据的基础上，强行构建一个自洽的价值观。幻觉 (hallucination) 可以看成是自洽后的自然体现。

很多新的科学发现，恰恰就是因为在自然界遇到了某个无法被现有理论解释的「错误」，无法自洽，因此必须抛弃旧的理论。所以这大致可以解释为什么迄今为止，没有一个大语言模型可以自发的做出新的科学发现，因为模型本身没有能力判断是非。

# **让你恼羞成怒的新技术可能让你发大财**

最让你气急败坏，恼羞成怒，而又无可奈何的新技术，最有可能让你发大财。

恼羞成怒，本质是遭遇一种 "narrative violation"（叙事的违反），违反的次数越多，跨越的时间越长，信号就越强烈，这是上帝在提醒你必须修改自己的思维模型。

发现自己的「无能」，但意识到只要思维模型转变就可以用实际上较小的代价变成「有能」，然后就会无比兴奋。当然这个搜索过程中必须花功夫，筛选掉很多骗局。

马基雅维利谈创新：「没有什么比开创新秩序更加难以掌握，更危险去实施，或者在成功上更加不确定了。因为创新者在所有从旧秩序中获利的人那里都有敌人，在所有从新秩序中可以获利的人那里却只有不温不火的支持。这种不温不火，部分来自于对敌手的恐惧，因为他们有现有法律的支持；部分来自于人类的不易信任，他们不会相信任何新事物，除非自己有了实际体验。」这也是为什么让你气急败坏恼羞成怒的新技术有巨大价值，因为这可能意味着新技术正在跨越「支持者的力量迅速超越反对者的力量」的鸿沟。

# **事件驱动的投资法具有反身性**

「事件驱动」（event driven）的投资法，长期看，投资效果是平庸的。因为这种投资策略具有反身性，你被事件驱动，竞争者也学会被同样的事件驱动，竞争过程中大家不断推高溢价，最后都赚不到钱。而且整个过程会很累。

「事件驱动」的风格之所以流行，是因为它很容易让人产生「我做了点什么，就产生什么效果」的幻觉，尽管这个效果衰减速度很快，甚至可能变为负，那是几天之后的事情了。即使失败，当事人不缺自我合理化的借口，然后又会满怀希望地寻找下一个事件来驱动。
