# 公开表达是效率最高的笔记

大规模的书面公开表达，是一种创造和存储各种素材的方法。素材多了，有的时候一些新的思维链就非常自然的[[涌现]]。但是如果不写出来，不公开放出来，就会阻碍和限制思维链的自然涌现。

社交媒体其实是效率最高效果最佳的笔记，它本质上让思想具备了「可组合性」(composability)。外人的评论可以给你帮你[[试错与纠错|纠错]]，增加新的角度，也可以让你产生更多的想法。于是思想便有了「[[复利]]」。整个过程不费力，自然而然。孤立的笔记工具做出来的笔记，看起来更整齐，有仪式感，但没有复利也是枉然。

# 基于人类反馈的强化学习

研究 GPT 之类的语⾔模型如何变得越来越聪明，就可以帮助⾃⼰变得越来越聪明；分析这些语⾔模型的缺点，为什么会顽固不化地重复弱智的错误，也可以⽤来更好地提醒⾃⼰，及早避开这些缺点。

⼤语⾔模型如 ChatGPT 的培训，有个概念叫做「基于人类反馈的强化学习」（Reinforcement Learning from Human Feedback，简称 RLHF）。简⽽⾔之，就是每次模型⽣成⽂本，⽤⼈⼯反馈作为性能衡量标准，优化模型。这⾥⾯的第⼀个挑战是⼈⼯反馈⽐较昂贵；第⼆是不同的⼈对同样的输出会有不同的反馈，让语⾔模型⽆所适从。

正确使⽤社交媒体，可以看成是对⾃⼰的 RLHF。粉丝越多，获取反馈的成本就越低，这样培训⾃⼰的成本也越低，进步也越快。当然需要注意的是，迅速拉⿊没有任何价值的、不友好的反馈和抬杠。

很多⼈⽆法迅速变聪明的⼀个重要原因是，不敢公开发表观点，怕被嘲笑和露怯，这样永远⽆法发现⾃⼰的弱点，以获得真正的进步；或者是，把⾃⼰限在⼀个小圈⼦⾥，你好我好⼤家好的⼀团和⽓，互相吹捧和⾃我⿇醉。AI 则完全没有这种顾虑。

把⾃⼰的想法写出来的时候，因为要把各种数据和素材组织起来，写着写着就会发现⾃⼰的观点⾃然改变，或者得出新的结论。所以我在社交媒体上的发⾔，主要是帮助⾃⼰思考⽤的（⽽不是给别⼈看的），同时微观上每⼀步推导争取获得外界有益的反馈，帮⾃⼰更好地思考。

# 在⾏动中形成新思维

美国组织⼼理学家 Karl Weick：「我们更可能在⾏动的过程中，形成⼀种新思维；⽽不是在思维的过程中，促成⼀种新的⾏为」。

再加⼀句，再也没有⽐读书和写作更⾼效的⾏动了。写开源软件，可以看成是⼀种⼴义的写作。

# 论写作的六⼤好处和⼀个坏处

写⽂章是⼀个有很多好处的事情，但是这⾥有个前提，写作⼀定不能被他⼈限定议题或者时间，不能太在意读者的点击率。要凭着⾃⼰的兴趣写，不断探索「邻近可能性」(adjacent possible)，这样才能有创意，才能有持续的动⼒，才能有⾼质量的东西。

被他⼈命题为了完成 KPI 赶出来的东西，过程痛苦⽆趣，出来的⽂字也多为令⼈反胃的矫揉造作的怪物。

为了写⽂章你要强迫⾃⼰去收集⼤量原始信息和数据，在获得新的数据之后，你会发现你以前的错误观点就⾃然而然地改变了。可以把写⽂章看成⼀个⾃我教育，更加准确认识客观世界的⼀个过程。这也是为什么越到后⾯我就越懒得搭理有偏⻅的⼈，因为他们缺少太多第⼀⼿原始信息，没有办法去理论。

写⽂章可以⽅便⾃⼰更好地复盘。⼈的记忆随着时间的流逝很容易变得模糊，如果有⽂章留下，就可以更清晰地回顾当时的思路，发现⾃⼰的不⾜，并予以纠正。否则⼈们可能会误以为⾃⼰⼀贯正确，然后继续重复⼀些低级的错误。

写⽂章公开发表往往会得到意想不到的读者反馈，给⾃⼰多⻆度的，更全⾯的视野，这是闭⻔⾃嗨做不到的。但是很多⼈有个恐惧⼼理，怕公开发表⽂字会出丑或者被喷⼦攻击。这实际是⾮常不理性的。喷⼦可以直接拉⿊，但⾃⼰有缺点如果遮遮掩掩，那么永远⽆法提⾼。

写⽂章的第四个好处是，稍微复杂⼀点的问题，是⽆法凭直觉想当然地搞清楚的。写出来，不断写，从不同⻆度写，写着写着⾃⼰就会终于弄通的。⼈脑的⼯作内存 (working memory) 只能够存四到五个概念，所以聊天扯淡胡喷时的思考深度永远⽐不上写作。写作时内存可以⾮常⼤，而且可以从容不迫地慢慢完成。真正的深度思考，没有⽂字的记录表达，根本⽆法完成。

写⽂章的第五个好处是，可以不断⻓期积累，而且这些积累可以不断反复引⽤。这种滚雪球的积累效应是惊⼈的。财富的积累可能因为不可抗因素而迅速缩⽔，但⾼质量⽂字的留存则⽆法被毁灭。若⼲年后看看很久前⽂字中的预测⼀⼀实现，恨不得从肩膀上伸出⼀只⼿拍拍⾃⼰说，「⽼王，真有你！」 :)

写⽂章的第六个好处是，这是⼀种 1 对 N 的社交，而 N 可以不断增加⽆上限。⻓期看其传播效率和有效性远远⼤于任何其它社交⽅式。更重要的是，因为 N 可以⾮常⼤，所以你可以⾮常挑剔，只选择和那⼀小部分对你有兴趣的读者沟通，而不必浪费时间和不理解你的⼈去鸡同鸭讲。

当然，写⽂章也有⼀⼤坏处：花时间！⾼质量的⽂章要花很多很多时间！但是因为前⾯的六个益处，这些时间最终都是值得的。

# 让读书产⽣好处的最简单办法

让读书产⽣好处的最简单办法是，⼀旦有灵感和想法之后，⻢上写出来，公开发布在社交媒体上，即使不成熟也没关系。写的过程也是⾃⼰深度思考的⼀个步骤，外⼈的有价值评论可帮你不断推敲，或给你带来新的线索，积累多了⾃然会出深刻的洞⻅。⼀个⼈孤⽴封闭的傻读写笔记，很难迅速提⾼思考深度。

和外⼈⾯对⾯交谈，可以看成是搜集信息的⼀个⼿段，但⽆法产⽣⾼质量的思考，⾯对⾯交谈时的各种情绪和⽓氛的因素可能⼲扰⾃⼰的认知，对决策质量产⽣负⾯效果。

有价值的深度思考，可以看成是由 N 个原来没有关系的组件发⽣连接，然后这种连接极⼤提⾼了解决某个问题的效率。读书就是不断搜集各种新概念的组件，然后通过社交媒体把⾃⼰的碎⽚思维扔出去，获得评论和新的线索，数量上去了，开放⽹络的效率⾃然碾压任何封闭的⼀个小区间。

过去⼏年很多想法，都是写的时候⾃然而然发现，而且彻底内化。不能提前预测，也⽆法逼出来，要积累到⼀定程度⽔到渠成才⾏。

# 有了想法你就写

1959 年，美国⼼理学家 Milton Rokeach 在密西根州的小镇 Ypsilanti 的⼀家精神病院开展了⼀个实验：他找到三个都⾃认为是耶稣基督转世的精神病⼈，每天吃饭和睡觉都安排在⼀起，让他们⽩天共同做些事，彼此有充分的时间交流，看看有什么结果。

这三个⼈的对话持续了两年。起初，每天早上，每个⼈都试图苦口婆⼼地劝说其余两位，⾃⼰才是真正的上帝。每⼀个⼈，都可以讲述⼀个貌似逻辑合理的故事，解释⾃⼰为什么作为耶稣基督，跑到了密西根州的精神病院。

当 Rokeach 作为观察者，指出其故事的明显荒谬之处时，三个⼈都会⻢上话锋⼀转，然后继续坚称⾃⼰是上帝。

这三个⼈都常常会准确清晰地攻击另外两个⼈的逻辑漏洞，当 Rokeach 要求他们解释不可能⼀个地⽅同时有三个耶稣基督时，他们都会轻蔑地解释，另外两个⼈是被机器操纵的⾏⼫走⾁，或者是真正的精神病⼈。

当争吵激烈时，三⼈甚⾄要动⼿打架。后来⼤家的交流慢慢变得⽂明起来，有时还⼀起和睦地唱歌。但是三个⼈，对于只有⾃⼰才是耶稣基督转世的信念，深信不疑。

我们普通⼈对⽇常各类事物的偏⻅，偏执，其实并不⼀定⽐那三个精神病⼈强多少。常常看到的，⼈们在各种⽹络论坛，微信，微博上的鸡同鸭讲的激烈争执，各说各话，是不是有点像那三个病⼈都声称⾃⼰是唯⼀的耶稣基督转世？

如何避免分析问题时执迷不悟的陷阱？尤其是涉及到投资，⼯作和事业这些严肃的问题？

⼥作家池莉有本小说名叫「有了快感你就喊」，借⽤池⽼师的话，我的回答是：

**有了想法你就写（出来）。**

这是第⼀步。⼈们脑⼦⾥对各类问题的看法往往是⽚⾯的，感性的，细节不够清晰，观点实际上也不鲜明的。写下来，是⾃我思考，⾃省，把模糊的东西细化，把问题的主次梳理清楚的⼀个过程。

这个过程，要颇花⼀点时间，但是如果不花这个时间，就是胡喷⼀下，打打嘴炮过瘾，实际上是浪费更多⽆谓的时间。

把想法观点写出来，不是简单地记流⽔账，而是要有两个基本要素。

第⼀个要素是必须同时列出⽀持你的观点的证据，和[[猜想与反驳|反驳]]你的观点的证据。许多⼈⽴论时，只是看到对⾃⼰观点有利的证据，而完全⽆视反驳⾃⼰观点的证据，这样越想越觉得⾃⼰有理。

强迫⾃⼰花时间从反⽅的⻆度考虑问题，容易让⾃⼰也⼼平⽓和，而不被预设⽴场引⼊歧途。

第⼆个要素是，所有的证据都必须尽量争取定量化。如果不定量化，则⽆法⽐较孰轻孰重，⽆法分清谁是主要⽭盾，谁是次要⽭盾。

我的经验是，在收集资料和写作的过程中，因为有了更多的信息和更严谨的思考，你对⼀个问题的看法往往会⾃然而然地上升到⼀个新的⾼度。

第⼆步，把想法写好后，⼀定要公开发表，通过微信和微博之类的开放式平台，让你的观点经受更多⼈的挑战和冲击。否则你可能沉浸在⾃⼰的泡沫中天天兴奋地喊着口号，既不⾃知，也不能⾃拔。

也许他们可以告诉你⼀些从不知道的东西？也许别⼈从⼀个全新的⻆度和维度，可以给你更多的启迪？也许⼀个陌⽣⼈的⼀两句评论，就可以让你恍然⼤悟，发现⾃⼰的想法的漏洞？

只有在开放式平台经过⼤众评论的考验的观点，才能帮助你进⼀步提⾼认识，使你的看法，更加接近客观现实。

把⾃⼰的观点预测写出来，还有另外⼀个好处：如果⾃⼰的分析，⽇后证明是错误的，可以回头再看看当年这些⽂字，反思当时的分析框架有什么缺陷，从而⼒求以后不再重蹈覆辙。

否则⼈性的⾃⼤和选择性记忆，会让你犯了错，吃了亏，而不⾃知，还会继续认为⾃⼰过去⼀贯⽜逼正确，⼀贯先知先觉，那么以后继续重复那些幼稚可笑的错误，也就是不可避免的了。

# ⽤写作纠正⾃⼰的认知偏差

每个⼈对同⼀件事都不可避免地会有认识偏差，如果在投资上、⼯作上也有这种偏差，并且完全不可⾃拔拒绝接受不同意⻅，那么结果将是灾难性的。为了防⽌犯错误，可以采取下述步骤：

1. 如果⾃⼰对某件事有看法，把它写出来，为什么会有这样的结论？列出⽀持⾃⼰的证据。写出来的东西和⾃⼰胡思乱想是完全不⼀样的体验。
2. 第⼆点很重要，⾃⼰要从反⽅的⻆度来看，假设⾃⼰是个反对者，写出反对⾃⼰观点的证据。
3. ⽀持和反对⾃⼰的证据要尽可能定量化，这样可以明确哪些因素是重要的，哪些是微不⾜道的。
4. 写出的东西要尽量在微信、微博、推特等渠道公开发表，看看外⼈有什么不同⻆度的批评意⻅，帮你指出你的逻辑漏洞，这样可以避免⾃⼰陷⼊⾃⼰的泡沫⾥而不⾃知。

# ⾃下而上写作

1/ 对于⼀个真正做⾃⼰有兴趣的事情的⼈，做事本⾝⾃带动⼒。

2/ 写⽂章时收获最⼤的实际上是作者⾃⼰，作者对问题的理解深度，远超普通读者想象，也远超作者⾃⼰起初的想象。

3/ 把重要问题理解透了，⾃然会在投资或别的事情上获得不菲的回报。

4/ 所以没有套现压⼒，不容易被分散注意⼒。

5/ 套现压⼒越小，创作的⾃发兴趣越⼤，更深度，最终会吸引⼀些有类似兴趣和理念的同道，形成社区。

6/ 社区⼈数和质量越⾼，会系统性地把⾃⼰的综合能⼒全⾯提升。

7/ 最终会在意想不到的地⽅，有更多新的发现，把以前担⼼关注的问题⼀个个变成伪命题。

写作时，⾃下而上地写更容易，也更愉悦好操作，把⼀些底层细节知识积累到⼀定程度，然后串起来，发现更⼤的统⼀的逻辑；如果先确定好命题，⾃上而下地写，后⾯越研究，发现问题越多，越⽆法驾驭。

⾃上而下地写，⼀旦操作起来，⼤把时间在找东西找素材，或发现事情不是像原来想的那样，然后很容易搁浅。类似的，做科学实验时，主要时间都在找东西。这种有时间压⼒，天天要去找东西赶进度的⽣活，极为不爽，⻓期效率还极低。

就好像⼀些科创板的⽼板，虽然上市，但⾃⼰五年内⽆法套现，还要天天跑业务各种压⼒，看似⾝价很⾼，但实际等于变相的五年有期徒刑，五年后能否⾃由还不⼀定⾃⼰说了算。外⼈只知恭喜⽼板发财了，不知⽼板⼼⾥各种苦。

创业投资的最终⽬的是保持⾼度⾃由和多重[[可选择性|选择权]]，但⾃上而下的操作，为了解决⼀个问题搞出 N 个新问题，成了复杂度的囚徒，完全违背初⼼。
