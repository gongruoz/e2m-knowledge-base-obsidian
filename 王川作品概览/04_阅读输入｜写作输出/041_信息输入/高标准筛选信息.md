# 被动从媒体接受信息的问题

如果一个人只是被动从公开的媒体渠道接受信息，会发现里面宣传的人物基本都是有一点好事就会十倍百倍的往天上吹，出问题的时候大多都是悄悄黯然离场，完全看不到。 这会给被动接受媒体喂食信息的人，一个顽固的心理偏差：永远严重低估风险，永远羡慕那些还没出问题还没爆仓的人的海市蜃楼和昙花一现，永远在焦虑（羡慕别人的时候焦虑，自己爆仓之后更焦虑）。

# 不用每天追新技术

新技术进步不用每天追，每个月看一下整体进展就好了。技术进步每天都发生，某个行业最多只需关注头部百分之一的公司。而即使是那头部百分之一的公司，也只需要关注它的最重要的一两个产品就好了。

如果相关信息，不能马上为自己所用，提高日常的效率，或者对自己躺平发财看不出什么价值，默认应当先放一放，再等一等。真正的好东西，晚几个月，晚几年上车也没事的。巴菲特在乔布斯死了五年之后，2016年才上了苹果的车，照样赚了一千多亿美元。

过度追各种高新科技的各种细节，就意味着浪费大量时间关注那 99％的非头部公司，关注大部分无关紧要的产品功能，不仅没有效益，而且把自己搞得像个日内交易者一样焦虑。焦虑一圈下来后更加心穷，时间穷，腰包穷。

# 过载的信息里面更容易搜索到高质量资料

虽然很多人抱怨移动互联网时代信息过载，太多垃圾信息分散注意力，让人上瘾；但是：你在这看似过载的信息里面，可以更容易地搜索到高质量资料，让你兴致勃勃地去钻研，乐此不彼。没有人真正想回到那个通讯闭塞，查点资料都要费几个小时跑到很远的地方，很多劣质信息以讹传讹永远无法被纠正，苦于缺乏信息而面壁发呆的时代。如果继续推导，未来信息的爆炸和表面上的过载问题只会愈演愈烈，此时筛选和检索的能力越来越重要，但单纯抱怨信息过载就是矫情。

@guijiewan：这些离散的信息，比比较容易让人把触角延伸出去。

这样你很容易找到新的外在有价值的增长点去配置资源，而不是孤立地浪费时间精力，愤怒地空转。

# ⼀半做减法，⼀半做加法

⽣活⼯作就是⼀个⼀半时间做减法，⼀半时间做加法的循环往复，不断优化⾃⾝信息和能量效率的过程。

⼈们的盲点是，做减法时不够果断不够狠，因为做减法时总会产⽣短期的表⾯上的损失，所以直觉本能上会犹豫。只有逼到墙⻆没得选了，才会极不情愿地，⾮常吝啬地做⼀点点减法。

但做完减法后，才会有时间精⼒去做新的加法，引⼊新的元素，迅速适应环境的变化，获得更⾼的效率和回报。

这本质上和断⻝减肥，让低效公司迅速破产才能迅速重新开始新的有机增⻓，是⼀个机制。

做减法包括切断所有⽆效或低效社交和纠缠，放弃任何⻛险和收益不对称的折腾，放弃任何不能提⾼你的⻓期效率的重复性⼯作，等等。

什么都想要，最终会因为资源捉襟⻅肘，顾此失彼，可能什么都得不到。什么都敢咬⽛放弃，则可以保证始终抓住重点，⼤概率最终脱颖而出。

# 输⼊信息狭隘，近乎精神病

1. 对于世界错误的认知，本质来⾃于偏狭的信息输⼊渠道。
2. 这表现于：
    - 知道的少，
    - 没有意识到还有很多不知道的东西，
    - 因为掩耳盗铃或其它负⾯情绪，拒绝摄⼊让⾃⼰不适的信息，
    - 因为理解能⼒匮乏，⽆法识别消化周边的信息，
    - 因为懒惰或信息获取成本⾼，而不去主动寻找新信息。
3. 结果都是⼀样，信息输⼊渠道和信息输⼊类别极为偏狭。好东西就在眼前也认不出来。危险就在眼前，也不知道规避。
4. ⼤脑对世界的思想模型，其基础是建⽴在外界信息输⼊管道的，是会⾃动⾃圆其说的，是会顽固抗拒任何其它（建⽴在更⼴泛信息输⼊渠道的）解读的，是不可理喻的，是⻅了棺材也不落泪的。
5. 为了防⽌⾃⼰成为⾃⼰鄙视的那种⼈，必须主动地，系统地，忍受⼀定不适感地，不带预设⽴场地，坚持不懈地，⾼效率地吸收处理外界[[涌现]]出来的各类信息。这样才能不断调整对于客观世界理解的思维模型。
6. 古⼈云：「知耻近乎勇。」可以这样说：「输⼊信息狭隘，近乎精神病。」
7. 社交媒体上各种⽇常打嘴仗，可以看成是不同类别的精神病⼈的冲突。
8. 因为如果知道对⽅是不可理喻，就不会⽆聊到要耗费宝贵能量去争辩。要么沉默，要么拉⿊。
9. 过度拟合的量化交易策略，技术分析，是⼀类精神病态。因为它赖以决策的量化参数，K 线图，等等，只是外界输⼊信息的很小的⼀部分。但是被交易员⾃我合理化为认识客观世界的全部信息。量化交易策略加⾼杠杆，是精神病态的⼀种体现。直到某天⾦融⻛暴，爆仓。
10. 因为媒体渲染的各种⾮常稀有的事情，⽐如杀⼈放⽕，⻋祸，各种灾害，中彩票，而被误导以为这是⽣活常态，⻓期处于过度担忧或幻想暴富等极端情绪之中，也是精神病态的⼀种体现。
11. 发现「特⽴独⾏的正确的」投资机会，从这个⻆度看，就是发掘寻找，因为信息输⼊渠道的偏狭而表现出来的强⼤的群体精神病现象，和它带来的机会。当思维模型固化时，⼈性会拒绝来⾃模型外的信息输⼊，机会就在⾯前也会被⾃动过滤。前提是，你必须清楚知道你掌握了什么被⼤众顽固拒绝理解的信息。
12. 低质量信息渠道，虚假信息，和信息传输的内在偏⻅性，是每个⼈都必须⾯对解决的问题。
13. 获得⾼质量信息，要么必须⾃⼰花很多时间，建⽴系统；要么需要有⾦钱的投⼊。如果还没有意识到⾃⾝的信息渠道需要系统性地建设，这本⾝就是⼀个⼤问题。
14. 需要意识到虚假夸⼤的信息，是⼈间常态。通常你所看到听到的信息，都是信息发布⽅所希望你看到的。重⼤决策，必须反复从多个⻆度，多个独⽴的信息渠道去验证核查。否则依靠直觉，被虚假信息所诱导，代价是惨重的。
15. 还有⼀种更阴险的问题，是信息传播的内在偏⻅和倾向性，以及相关的[[回报递增，路径依赖|路径依赖]]的后果。⽐如科技创业媒体⼤量报道的内容是某某公司⼜融资多少多少亿，估值多少多少亿，各种祝贺；但⼤部分公司即使融资之后，最终倒闭，或者⻓时间痛苦挣扎，相对报道要少很多。
16. 这样路径依赖的后果就是：读者会有个错误印象，融资成功是企业成功的主要标杆，融资的能⼒是被追捧的，天天思考如何去做 PPT 融资，而不是去思考商业本质。投资者也会很有挫折感，把钱给了⼀批能吹⽜演戏的创业者，但不知道如何投到好项⽬。
17. 媒体的报道，往往⽕⼒集中在过去的成功者⾝上，和他们过去成功的路径和策略。这类信息会很⾃然地带来⼤批模仿者，⼀拥挤，过去的路径/策略效果就差多了。
18. 所有事情，都有⼀个信息获取成本的问题。避免在信息获取成本⾼的地⽅去和别⼈竞争，否则别⼈放烟幕弹，释放虚假信息，你⽆法甄别。反过来说，你可以低成本获取⾼质量信息的空间有多⼤，你的⾃由活动空间就有多⼤。
19. 很多⼈从来不思考信息获取成本的问题。投资业搞尽调，每天到处⻜，倒时差/饮⻝睡眠不规律/天天讲很多话耗神，是要折寿的。可以反向考虑，什么是你⽇常⾮常喜欢做的事情，在做这些事时，你是否顺带着可以低成本地获取哪类⾼质量信息？以此为基础的信息优势，你可以把握哪些普通⼈很难把握的机会？
20. 实际可⾏的操作也许是这样的：
- 不断降低获取⾼质量信息的成本，先从⾃⾝周边做起
- 获得⼤量⾼质量信息
- 因为信息质量⾼，数量⼤，所以在某个局部可以更好地理解客观世界
- 在群体精神病发作时，可以利⽤局部优势，轻松冷静套利
- 再把套利所得，⽤于更加系统地建⽴更全⾯的信息获取的优势。
1. 传统信息获取⽅式是：⼀块⼀块⽯头翻过来，看看底下藏着什么东西，这个成本较⾼，相当于计算机科学中的 O(n) 复杂度。还有⼀种⽅式是，朝池塘⾥扔⼀块⽯头，激起⼀些波澜，看看⽔底下蹦出什么东西来，如果正确操作，成本 = O(1)。成本 O(n) 的⼈，有能⼒与成本是 O(1) 的⼈竞争吗？
2. 如果把赚钱当成砍柴，那么建造「低成本获得⾼质量信息」的系统就好⽐磨⼑。砍柴者众，利刃寡。磨⼑永远不误砍柴⼯。
3. 你不需要太多柴，只需要⼀把独特的，与时俱进的，永远锋利的⼑。

（注：O(n)，计算机学术语，指数量和系统⼤小 n 成正⽐；O(1) 代表某个常数，和系统⼤小⽆关。）

# 垃圾输⼊导致精神糖尿病

社交媒体上各种搞笑的段⼦，各类激发嫉妒和愤怒情绪的帖⼦，各类⽆孔不⼊精准投放的⼴告，⼤概类似精神上的垃圾⻝品（junk food）。看多了后会形成⼀种「精神上的糖尿病」，就是对严肃重要的东西渐渐缺乏能⼒去深⼊研究和剖析，沉溺于情绪的发泄或精神甜⻝⽆法⾃拔，⽆时⽆刻不需要吸收精神上的垃圾⻝品，否则就会迅速陷⼊枯燥⽆聊甚⾄抑郁的状态。

美国⼈口 1980 年之后的⼤⾯积迅速肥胖，很⼤程度上似乎可以归因为都市⾥各种唾⼿可得的廉价的甜⻝、饮料和快餐的全⾯普及。这后⾯有⻝品饮料公司的巨⼤经济利益在源头推动，个体如果不能⾃觉⾃制，默认的结局就是落⼊肥胖的陷阱。

这个问题的解药是：⾼度⾃我觉知，每天保持⼀定强度和时⻓的锻炼，尤其是⼾外的锻炼。谨慎选择你的环境和信息源，定期果断删减更新你的朋友圈⼦。

⼈的愚昧很⼤程度上是因为缺乏原始第⼀⼿的信息，因此潜意识⾥被诱导形成各种错误可笑的思维模型。不断追求各种原始第⼀⼿信息，是思维脱贫和物质脱贫的最有效有⼒的⽅式。

# 噪⾳和信息

「你必须⾃然而然地发现信息和噪⾳的区别，学会从噪⾳中寻找信息。进⼀步，理解信息的不同重要级。

信息本⾝不会告诉你这些艺术，只有浪费和错误才会教你明⽩。不是你⾃⼰明⽩的东西，对你根本没有⽤处，⽆⾮浪费记忆和时间。」

意识到对于不同阶段处在不同位置的⼈⽽⾔，噪⾳和信息的理解是不⼀样的。对于置⾝事外的观察者⽽⾔，传统⻋企如 Volkswagen、宝⻢、奔驰都是冢中枯⻣，它们做或者不做什么已经没有意义了。来⾃他们的信息基本上可以当噪⾳看待。他们已经进⼊⼀个⿊洞的 event horizon，⽆关紧要了。

对于信息和噪⾳的评估，最终取决于它是否让你更有效地获得更多能量（通俗说，赚更多钱），但这有时要很久后才能判断，而且跟具体背景上下⽂⾮常有关系。在⽣物界容易被噪⾳假信号迷惑，浪费能量的物种，很容易饿死淘汰。这⾮常残酷，但这就是事物运作的本质规律。

# 即时信息 vs ⼏年前的预测

意识到朋友圈和微信、微博和推特的很多信息，因为表达的都是倾向于要引起⼈们注意⼒和情绪反应的内容，所以会潜意识增加焦虑感。同时还有媒体为商业利益推波助澜，很难察觉抵抗。

这个潜意识的焦虑反应没法直接压制，只能多主动寻找更有深度更有趣的内容，来防⽌被杂⾳分散注意⼒。

⽐较有价值的内容，是看极少数⼈⼏年前，甚⾄⼗⼏年前对⼀些趋势的预测分析，而事后发展和⼤众直觉相反，却和他的预测框架基本吻合。这种分析，值得反复阅读追踪，真正理解其底层逻辑。

底层逻辑到表象的逻辑链条越复杂越⽭盾，就越没有⼈耐⼼看，但这才是普通⼈凭⾃⼰努⼒真正可以抓住的机会。

寻找真正⾼⽔平作者的最简单⽅法是看他⼏年前写的预测，这样也可以迅速理解其认知的局限性，而不是对其所有观点盲从。如果他分析问题的时间跨度太短，都是些今天涨了⼏块明天跌了多少点的⽔货，赶快取关。另外底层逻辑与情怀道德对错⽆关，而是去研究为什么会有强弱和攻守的易势。

# ⽤指数基⾦管理的⽅法利⽤社交媒体

1. 社交媒体号，追踪的数⽬不必太多，上限是 600，对标 S&P 600 smallcap index（标普小盘股 600 指数）。超过这个数⽬，很难带来实质信息价值。可能减少到 400 也⾏，对标 S&P 400 midcap index（标普中型股 400 指数）。
2. ⼀个微博或者推特号，是否值得关注，最简单的⽅法，第⼀是看他有多少粉丝，粉丝数⼀般小于五百的，就不值得关注。如果他的信息有价值，就⾃然而然地会吸引新的粉丝，使粉丝数超过 500，再关注不迟。这就好⽐天使投资⼀般⻛险很⼤，等到他收⼊/利润超过⼀个量级[[阈值|临界点]]之后再研究不迟。
3. ⼀些号虽然粉丝数⽬巨⼤，但仔细⼀看信息没有任何营养，全是营销/情绪宣泄/或者重复⽆新意的噪⾳，不要去关注。
4. 是否追踪某⼀个号，可以问这样⼀个问题：这个号输出的信息流，是不是可以让我最有效地实时追踪变化的世界的真相，并因此⽽受益？如果是，就加。这是唯⼀标准，而不是个⼈好恶。
5. 宣泄情绪的意淫⽆助于个⼈成⻓，而如果能够不断真正成⻓就完全⽆需意淫。
6. 如果⼀个号很久没更新，或者其输出信息流的价值明显不如同⼀个领域的另外⼀个⼈，应果断取关，而去关注信息价值更⼤的⼀个⼈。
7. 信息价值的⼀个判断标准，在于它减少你对世界的模糊理解的不确定性，让你对真相看得越来越清楚。
8. 每删⼀个号的同时，要强迫⾃⼰加⼀个关注的新号。这样确保⾃⼰不过于偏狭。
9. 寻找关注新号的⽅法，⼀是看你关注的⼈有关注什么别的⼈，⼆是搜索某个你感兴趣的具体话题。
10. 时间⻓了，你定制的社交媒体上的这些实时信息流，就会⾃然而然地成为帮你理解最真实世界的⼀个有效窗口。⽐报纸或其它媒体更真实，而不会让你被各种喧嚣杂⾳误导浪费时间。
