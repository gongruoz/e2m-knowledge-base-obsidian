# 多读世界近代现代历史

多读世界近代现代历史（1600-2000），世界运作的基本规律，基本套路都在⾥⾯。

太早了，早于 1600 年之前，很多史料可能模糊不准确，数量太少不详尽，可能断章取义得出错误结论。

太近的历史，很多事情还在发展进⾏中，不能盖棺定论，很多信息还隐藏着没有公开披露，如果只看表⾯叙事的假象，也容易得出错误结论。

阅读世界历史的⼏个着眼点：

1. 张三和李四为了什么根本原因（争夺什么样的资源）而发⽣冲突；
2. 冲突慢慢加剧，激化和最终⼤爆发的过程和中间各种噪⾳和烟雾；
3. 张三战胜李四的根本因素是什么，哪些结局是必然，哪些是偶然；
4. 为什么失败者⾯临必然的败局还⼼存侥幸，决策者的思考⻆度是怎样的，等等

读世界历史是「⻅世⾯」和洞察本质的最便宜最快的⽅法。⼀个好处是思考框架的时间维度拉⻓，⾄少五年⼗年以上，因此思考的问题性质结构完全不⼀样，反而更容易。另⼀个好处是知道在什么场景下有能⼒做确定性较⼤的判断，在什么场景下则没有能⼒做这种判断，没能⼒判断时则选择不浪费精⼒做⽆⽤功。

⼤量阅读世界历史，就是软件 2.0 的⾃我培训⽅法；不读历史只看局部的现实的数据去试图⽤单⼀的叙事⽅式（好⽐⼈为设计的算法）理解世界，即使精度再⾼，也可能陷⼊软件 1.0 的⽆解的死循环⾥⾯不能⾃拔。

如果你抱怨媒体充斥着噪⾳和假消息，本质还是历史读得太少。设⾝处地去读各种⼈物传记历史，就会意识到噪⾳，假消息和媒体业的歇斯底⾥，实际是常态。

学者的论述缺乏鲜活的真实感，还是过于单薄。读⼈物传记，⽐较容易有代⼊感，更深刻地理解其当时的信息输⼊，观察⻆度，⼼理状态，以及决策误区。

很多时候我们说「纸上谈兵」，是因为⼀些宏⼤叙事的史书，⽆法复原当事者整个过程中的「情绪记忆」，和基于丰富情绪记忆形成的丰富直觉。这种直觉能让⼈对重⼤利好，或者特别危险的信号⾮常敏感，如果⽆法亲⾝经历，只有多读⼈物传记才可能补充这⽅⾯的不⾜。

如果能够把观察⻆度和⽣活经验通过阅读扩⼤五到⼗倍以上，⼀定觉得这个世界是个充满各种⿊⾊幽默的滑稽剧场：可以提前预知谁和谁之间⼀定会发⽣结构性冲突，谁⼀定会在某个阶段遇上他⽆法理解也跨不过的坎，在什么阶段对于某个⻆⾊⼀定存在较⼤机会，等等。

# 读历史是对自己的端对端训练

五代十国军阀打仗有个经验教训：如果自己的力量远强于对方，可以派手下出征；如果大家力量差不多，甚至自己略微差一点，那么主帅一定要尽早亲自上场，否则士气不振，甚至容易发生自己的将领反叛投降，然后一败涂地，彻底崩溃的现象。

正面的例子是后唐的李存勖，后周的柴荣。反面的例子是后梁的朱友贞，后晋的石重贵，前蜀的王衍，后蜀的孟昶，南汉的刘鋹。当然，上上策还是平时注意繁荣自己的经济，给军士合理的激励机制，让自己的实力远远强于对手，这样根本无需临时抱佛脚。

历史上很多人的灭亡不是犯了一个简单的错误就马上完蛋了，而是缺乏经验和自律，在很长一段时间内，犯了一连串错误。不给自己设置多个安全阀门，应对复杂的风险。为了解决一个眼前的问题鲁莽从事，结果制造出 n 个新的问题，让自己越来越被动。每次犯错误后，不修内功，而是想取巧，做表面功夫，越绝望就越慌不择路，越慌不择路就越绝望。越年轻越没有实战经验的人，越容易犯这种错误。

后梁朱友贞（888-923）在 913 年上位称帝，只有 25 岁。他犯的第一个错误就是没有处理好和魏博的关系，当年借魏博节度使杨师厚的帮助上位，后来又着急削藩，杨师厚 915 年死后，朱和近臣弹冠相庆，然后急吼吼的要把魏博分割，最后逼反魏博投入李存勖的怀抱。其实即使一个独立的魏博，作为一个缓冲国，也能成为抵御后唐的坚实屏障。

第二个错误就是只信任当初扶他上位的几个近臣，未能广开言路，使更多部下离心离德，最终导致康延孝投靠后唐，出卖段凝进攻后唐的计划。

第三个错误是因为自己缺乏长期的冲锋在一线的经验，居然把主力完全交给段凝，而导致汴梁守卫完全空虚。最后被唐兵奇兵包围，自杀而死。其结局和 470 多年后朱允文的南京空虚，被朱棣包围破城非常类似。

多读各种历史就是对自己的「端对端训练」，而且每次接收新的训练数据后，都能感知到自己之前的局限之处。用历史数据培训，比在现实中亲自接受教训的优点是：历史数据的训练，你马上可以看到结局，可以吸取教训；现实中，很长时间完全没有[[设计自己的反馈机制|反馈]]，有时吃亏上当是要若干年后才恍然大悟。

# 历史中的财政结构

读历史，如果不了解军阀斗争背后各派的财政结构，只是看表面张三和李四的争斗，基本就是白读了。

如果只是关注某某如何诡计多端，某某如何英勇、如何高尚、如何卑鄙等等，被这些不涉及问题本质的表象特征充斥了头脑，基本就会不可救药地成为一个 sb。

媒体上抛头露面的各种政治人物，本质都是其背后的财政结构的泡沫。

同一个政客，在不同的年代如果表现判若两人，本质是因为背后的财政结构和力量发生了变化。

类似的，拳击手的攻击力，不是来自胳膊，而主要来自大腿的力量，以及上臂、腰腹部与大腿协调发力攻击的能力。拳击训练更多的是训练这种高度协调的本能。胳膊粗、力气大，但缺乏这种专业训练的人，在拳击场上基本没有胜算。就好像一个军阀，如果财源枯竭，募不到更多兵，没有足够粮草，个人的舞枪弄棒能力再强也无济于事。

唐高祖李渊起事时，向突厥借兵，说：「征伐所得，子女玉帛，皆可汗有之。」

安史之乱后，唐肃宗向回纥借兵，说：「克城之日，土地士庶归唐，金帛子女皆归回纥。」

湘军攻破太平天国的天京之前，欠饷已一年多，眼看撑不下去，有些士兵就要哗变。因此，攻破之后，曾国荃放任士兵大肆劫掠来代替军饷，高层官员睁一只眼闭一只眼，也属必然。

如果某人为历史上的某个军阀的丰功伟绩欢呼，但不知道军阀的钱粮从何而来，那他如果穿越回去，大概率自己就会成为钱粮的来源。

类似的，巴菲特曾说：「如果你上了牌桌，但不知道 sb 是谁，那 sb 就是你。」
